## 현재 화면과 기능

- **선택**에서 빈 공간 드래그로 영역에 닿는 직선·기본/자유/무차별곡선·합·점·점선을 선택합니다. 영역은 포인터를 놓으면 사라지고 선택된 도형/목록은 강조합니다. Ctrl/Cmd+클릭은 추가·해제, Shift/Ctrl/Cmd+영역 드래그는 추가 선택, 빈 공간 클릭·Esc는 선택 해제입니다. 다중 선택 패널에 선택 목록·개수·삭제/선택 해제를 제공합니다. 도형 하나를 다시 클릭하면 그 도형의 기존 개별 편집·이동으로 돌아갑니다.

- 곡선 생성 패널의 **무차별곡선** 네 버튼으로 바로 추가합니다. 기존 기본/세 점 자유 곡선도 유지합니다. 새 곡선의 복제·이동은 종류별 규칙을 유지하며 사본의 이후 모양 변경은 서로 전파하지 않습니다. 완전보완재는 꺾임, 서로 다른 기울기의 완전대체재는 적절한 축 모서리를 직선에 맞춥니다. 준선형의 선형 축은 기본 y이며 x로 전환할 수 있습니다. 고유 이동은 Shift보다 우선하고 Alt는 자석만 생략합니다.

- 캔버스 위에 **선택·직선·곡선·점·점선·칠하기**를 두며 현재 도구만 강조합니다. 곡선 버튼은 세 점 그리기를 시작하고, 생성 패널의 **기본 곡선** 그림 버튼으로 직각 쌍곡선·우상향·우하향을 바로 추가합니다. 작은 펼침 화살표는 제거했습니다. 합치기와 격자는 구분된 명령입니다.
- 오른쪽 위에는 생성 옵션·복제/합산·선택 도형 편집·빈 상태 중 하나만 표시합니다. 복제 버튼은 합치기와 같은 공통 명령 스타일로 항상 표시하며 선택이 없어도 복제 가능한 도형이 있으면 열립니다. 분류·휘어짐은 펼침 항목입니다. 아래 도형 목록에서 선택·계층·폴더를 관리합니다.
- 선택 도구에서 직선 전체를 드래그하면 자유 곡선·기본 곡선(접선 연장 포함)의 보이는 접선에 기울기를 유지하며 위치만 맞춥니다. 16px 포착·24px 해제로 떨림을 줄이고 공통 접점 원·글씨·대상 강조를 표시합니다. Alt로 생략하며 한 드래그는 한 undo 단계입니다. 새 binding은 만들지 않고 움직이는 직선에 종속된 곡선과 연결된 통과 직선은 제외합니다.
- 반대로 독립 곡선 전체를 드래그해 직선에 접하게 붙일 수 있습니다. 곡선 모양을 유지하면서 직선의 현재 기울기에 맞는 접점을 두 구간 전체에서 찾으며 원래 가운데 접점으로 제한하지 않습니다. Shift 축·16/24px·Alt·공통 접점 표시·한 번의 undo를 공유하고 새 접점은 점 생성 포인터에도 잡힙니다. 대상 직선이 움직이는 곡선에 종속되면 제외합니다.
- 같은 그래프의 기존 점도 전체 이동의 자석 대상입니다. 직선은 점까지의 법선 거리로, 곡선은 정확한 최근접점 또는 Shift 잠긴 좌표의 교차점으로 평행이동량을 계산합니다. 점은 그대로 두고 도형만 이동하며, 축 띠 안쪽의 보이는 점도 사용할 수 있습니다.
- 그래프 설정은 이름·사분면·축 이름/방향·축 간격·전체 삭제를 모읍니다. 입력은 즉시 반영하며 완료/닫기로 돌아갑니다. 상단 배치와 저장(JSON) 버튼을 유지합니다. 자 버튼은 화면에서 제외했습니다.
- 최대 3×3 배치와 그래프별 독립 도형·축·사분면·반전·간격을 지원합니다. 배치를 줄여도 숨긴 그래프를 보관합니다. 생성·계층·복제·관계·배치는 최근 100단계 undo/redo에 포함합니다.
- 점은 기본 생성 ON, 좌클릭으로 만듭니다. 점·점선은 각각 기본 보정 ON이고 Alt는 보정을 잠시 생략합니다. 점선은 독립된 유한 선분으로 길이·측정 눈금이 없습니다.
- **합치기**는 같은 그래프의 직선·기본 곡선 두 개 이상을 수직합/수평합합니다. 기본은 독립 변수 0 이상·음수 기여분 0 처리이며, 해제하면 부호를 그대로 더합니다. 원본 수정은 자동 반영하고 원본 삭제는 의존 합도 함께 삭제합니다. 생성 후 합 편집으로 돌아갑니다.
- **자유 곡선**은 시작점→끝점→지나는 점의 유한 곡선입니다. 세 점·접선 방향·양쪽 휘어짐·전체 이동과 ∪/∩/⊂/⊃를 지원합니다. 세 번째 점을 직선 근처에 찍으면 접선 관계를 연결합니다. 수동으로 직선을 선택해 연결하는 편집 UI는 최신 요청에 따라 제거했습니다.
- **최저점 표시→이 점을 지나는 직선**은 자유 곡선→최저점→직선을 추적합니다. 연결 해제 또는 원본 삭제 시 현재 형태로 남습니다. 연결된 점·통과 직선은 해제 후 직접 이동하며 직선의 기울기는 연결 중에도 바꿉니다.
