# 변경 기록

## 2026-10-28 · 자유 도식과 편집 UI

이번 반영은 이전 main(381e30c) 이후의 합산·자유 곡선·UI 정리와 문서를 포함합니다. 배포는 포함하지 않습니다.

- 같은 그래프의 직선·기본 곡선을 수직/수평으로 합산합니다. 원본 참조를 저장해 변경을 따라가고 서로 다른 절편의 꺾임·0 기여분을 보존합니다. 음수 처리 옵션과 지원하지 않는 수직/수평 원본 안내를 추가했습니다.
- 세 점 자유 곡선, ∪/∩/⊂/⊃, 접선 방향·양쪽 휘어짐·전체/세 점 이동을 추가했습니다. 직선 접점·최저점·통과 직선의 관계, 연결 해제·원본 삭제 시 현재 기하 보존, 순환 방지와 수직 회전 경계를 지원합니다.
- 긴 도구 목록을 도구막대·현재 작업별 편집 패널·도형 목록·그래프 설정으로 정리했습니다. 합산까지 모드 배타성을 적용하고 기본 곡선의 방향을 명시적으로 선택합니다. HCI 조사 출처와 적용 판단을 문서화했습니다.
- JSON은 6→7에서 sums를, 7→8에서 sketches와 binding을 추가했습니다. 현재 8이며 내보내기만 제공합니다.
- 새 회귀는 합산 11개, 자유 곡선/관계 15개, UI 상태 4개입니다. 기존 87개를 포함해 전체 117개가 통과합니다.
- 현재 인계와 과거 기록을 분리하고 사용법·구조·JSON·검증·예시를 맞췄습니다. 기기 전용 .cmd 세 개와 dist/.local은 반영 대상에서 제외합니다.

현재 제한은 [인계 문서](../HANDOFF.md), 검증 범위는 [검증 문서](testing.md)를 따릅니다. 초기 접점 제안과 과거 구현 과정은 [이력](history/implementation-log.md)에 보존합니다.
