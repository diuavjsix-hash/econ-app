## v4 · 2026-11-08 · 글자 크기·마우스 휠 확대/축소·실행 파일 제외

### 글자 크기 키우기·마우스 휠 확대/축소

- 글자 단계를 한 칸씩 키웠습니다(본문 13→14px, 라벨 11→12px 등). 컨트롤 높이와 편집 패널 폭도 함께 늘렸습니다. 모두 `src/ui/tokens.css`의 토큰만 바꿨습니다.
- 그래프 위에서 **마우스 휠**을 굴리면 좌표평면을 확대·축소합니다. 원점과 축은 제자리에 두고 보이는 범위만 바뀝니다(0.2~10배). 위로 굴리면 확대, 아래로 굴리면 축소이고, 1배 근처에서는 정확히 1배로 돌아옵니다.
- 배율은 그래프마다 따로 기억하는 보기 상태입니다. 되돌리기 기록과 JSON에는 들어가지 않고, 도형은 같은 수학 좌표에 그대로 있습니다. 많이 축소하면 격자 간격을 2·5·10…으로, 많이 확대하면 0.5·0.2·0.1로 바꿔 격자가 너무 빽빽하거나 비지 않게 합니다.
- 에지워드 상자는 상자를 화면에 맞추는 형식이라 휠 확대를 하지 않습니다.

## v3 · 2026-11-08 · 점 맞춤 우선·Shift 수평/수직 표시

### 점 맞춤 우선·Shift 수평/수직 표시

- 찍어 둔 점이 16px 안에 있으면 교점·선·곡선·접점·절편보다 **점 맞춤**이 먼저입니다. 이미 다른 대상에 붙어 있어도 점이 들어오면 점으로 넘어갑니다. 생성(점·직선·자유 곡선)·손잡이·도형 전체 이동에 같은 규칙입니다.
- 지금까지 직선 도구만 찍어 둔 점에 붙었습니다. 점 도구·자유 곡선 생성·점 이동·자유 곡선 손잡이도 같은 `pointSnapCandidates`로 찍어 둔 점에 붙습니다(움직이는 도형과 그것을 따라가는 점은 제외).
- 자유 곡선의 지나는 점이 찍어 둔 점에 맞으면 직선 접하기보다 점을 지나는 쪽을 씁니다(직선 binding 없음).
- 직선 도구에서 Shift로 수평·수직에 잠기면 접선과 같은 방식으로 시작점에 **수평 맞춤** / **수직 맞춤**을 표시합니다(강조할 도형 없음).

## v2 · 2026-11-08 · Shift 접선 잠금·변경 기록 정리

### Shift 방향 잠금에 접선 추가

- 직선 도구에서 두 번째 점을 정할 때 Shift를 누르면 **수평 / 수직 / 시작점의 곡선 접선** 중 마우스 방향과 가장 가까운 방향으로 잠급니다. 시작점이 곡선 위(몸체·접점·교점·끝점 맞춤)에 있을 때만 접선 후보가 생깁니다. 두 곡선의 접점에서는 공통 접선이 됩니다.
- 접선으로 잠그면 공통 맞춤 표시가 접점에 **접선 맞춤**을 띄우고 그 곡선을 강조합니다. 잠긴 접선 위의 교점·절편·점에는 기존처럼 붙습니다. Alt+Shift는 접선을 빼고 수평·수직만 잠급니다. 곡선 밖에서 시작하면 이전과 같은 수평·수직 잠금입니다.
- 접선 계산은 `curve-contacts.js`의 `curveTangentsAt`(해석 곡선 종류·자유 곡선 이차 구간의 원본 기하), 방향 선택은 `ruler.js`의 `directionLock`입니다. 꺾임에는 접선이 없습니다.
- 그리는 동안만 맞춰 주며 관계를 만들지 않습니다. 곡선을 나중에 옮겨도 직선은 따라가지 않습니다. 모바일(Shift 없음)은 구현 대상이 아닙니다.
- 앱 401개·브라우저 2,557개·구문/경계 119개 모듈·빌드 통과입니다.

### 변경 기록 정리·작업 규칙

## v1 · 2026-11-08 · 디자인 시스템 개편·두 점 직선 도구

### 디자인 시스템 개편

- 레퍼런스(Figma UI3 속성 패널·Linear·tldraw/Excalidraw·Desmos·경제학 교과서 도판·Pretendard)를 정리하고 "종이와 잉크" 방향으로 화면을 다시 만들었습니다. 근거와 규칙은 [디자인 시스템](design-system.md)에 있습니다.
- 보라 강조를 걷어 냈습니다. 화면 틀은 따뜻한 흑연 회색이고, 현재 도구·주요 버튼은 잉크(거의 검정), 값 상태와 캔버스 선택·맞춤은 잉크 파랑 하나만 씁니다.
- 원시 값은 `src/ui/tokens.css`에만 씁니다. 공통 컴포넌트는 `src/ui/components.css`, 마크업은 `src/ui/controls.js` 생성기로 모았습니다. 화면 배치는 `src/ui/shell.js`, 아이콘은 `src/ui/icons.js`로 옮겼습니다. `src/editor.css`는 삭제하고 `styles.css`를 토큰만 쓰도록 다시 썼습니다.
- 도형 기본색을 `src/models/palette.js`로 모았습니다. 우하향은 파랑, 우상향은 빨강이고 곡선 종류마다 역할 색이 있습니다. 칠하기 색 이름은 파랑·빨강·초록·황토·보라·청록입니다. 이미 저장한 JSON의 색은 바뀌지 않습니다.
- 카드 안의 카드 구조를 없애고 그래프를 회색 작업 바탕 위의 흰 종이로 표시합니다. 도구막대와 상태 문구를 한 줄에 놓고, 직선 식은 수식 글꼴로 표시합니다. 도형 목록의 기호는 글자 대신 16px 아이콘입니다.
- `tests/design-system.test.js`가 토큰·팔레트·공통 컴포넌트 사용을 강제합니다.

### 선택 도구 복귀 통일·점선 버튼 제거

- 무엇을 만들거나 복제하면 항상 선택 도구로 돌아가고 결과가 선택됩니다. 이전에는 점·점선·칠하기·직선 도구가 계속 켜져 있고 곡선·합산·빠른 추가는 돌아가는 식으로 섞여 있었습니다.
- 툴바의 **점선** 버튼과 패널을 없앴습니다. 점선은 직선 도구에서 고릅니다.

### 두 점 직선 도구

- **직선** 버튼이 바로 직선을 추가하지 않고 직선 그리기 도구를 엽니다. 패널에서 **직선 / 반직선 / 선분**과 **실선 / 점선**을 먼저 고르고, 두 곳을 클릭하거나 드래그해 그립니다. 고른 값은 다음 선에도 유지됩니다.
- 시작점·끝점은 공통 맞춤(교점·절편·점·접점·최저점·끝점, 16px/24px, Alt 생략)과 Shift 수평·수직 고정을 사용합니다. 두 점의 x가 같으면 정확한 수직선(slope null)입니다.
- 선택한 직선의 설정에도 같은 종류·모양 버튼을 두고 기존 **점선** 체크를 대체했습니다. 이미 있는 끝은 유지하고 없는 끝은 보이는 부분 안에 새로 둡니다.

### 복제 가시성과 직선 접선 맞춤 (2026-10-30)

- 먼저 찍은 점을 지나는 직선·기본/자유 곡선 전체 이동 자석을 추가했습니다. 곡선의 정확한 최근접점/Shift 축 교차를 사용해 모양·기울기·점 좌표를 보존하고 Alt·단일 undo를 공유합니다. 자기 도형에 종속된 점은 제외하며 더 가까운 명시적 점으로 절편/접선에서 전환할 수 있습니다. 새 관계·패널은 만들지 않습니다.
- 직선 이동의 x/y절편·원점 자석과 점 생성의 절편 보정을 추가했습니다. 축 간격이 있어도 실제 교차 좌표를 사용합니다. 곡선 포인터를 점 도구의 원형·좌표 하나로 통일하고 작은 곡선 메뉴를 패널 빠른 추가로 바꿨습니다.
- 곡선 자체의 이동에도 직선 접선 자석을 적용했습니다. 복제한 곡선이 기울기가 달라진 복제 직선의 접점으로 모양을 유지한 채 평행이동합니다. 특정 경제 모형의 전용 조작을 추가하지 않고 기존 직접 조작을 확장한다는 원칙을 AGENTS.md와 설계 문서에 명시했습니다.
- 복제 기본값을 ‘옆에 생성’으로 바꾸고 반복 사본의 같은 위치를 피합니다. Shift+드래그에 수평/수직 제한과 해당 축을 유지하는 스냅을 적용했습니다. 수동 ‘직선에 접하기’ 펼침 메뉴를 제거했습니다.
- 자유 곡선↔직선 교점·접점을 표시 선분 대신 원본 이차식으로 계산해 복제 후 새로 맞춘 접점에도 점 포인터가 붙도록 수정했습니다. 복제는 비선택일 때 흰색·회색으로 표시하고, 곡선 그리기 1/2/3단계를 그래프 안에서 안내합니다.
- 복제를 캔버스 위 도구막대로 옮겼습니다. 선택 도구로 직선을 드래그할 때 같은 그래프의 자유/기본 곡선의 접선 위치에 평행 이동으로 맞춥니다(정확한 이차 곡선 미분·수직선 null·접점 표시·Alt 생략). 새 따라가기 관계는 만들지 않습니다.
- 당시 포착/해제 거리는 10/18px였고 이후 16/24px로 통일했습니다. 이 기간에 앱 테스트가 126개에서 175개로 늘었고 Windows 서버 3개와 실제 브라우저 조작을 확인했습니다.
