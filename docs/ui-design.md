# 화면 정리의 근거와 적용

2026-10-28. 사용자 목표는 경제 그래프를 노트처럼 자유롭게 그리는 것입니다. 기능이 늘어나면서 도구 탭과 설정이 뒤섞인다는 피드백에 따라 기존 기능의 진입점·배치·모드 표시를 정리했습니다. 아래 배치는 HCI 원칙을 이 프로젝트의 사용 흐름에 적용한 설계 판단입니다.

## 확인한 자료

1. **Ben Shneiderman, Designing the User Interface의 Eight Golden Rules**: 일관된 조작, 피드백, 오류 예방, 쉬운 되돌리기, 사용자의 통제, 기억 부담 감소를 강조합니다. [메릴랜드대학교의 저자 설명](https://www.cs.umd.edu/~ben/goldenrules.html)
2. **MIT 6.831/6.813, Learnability 강의**: 직접 조작은 대상을 계속 보여주고, 클릭·드래그·명시적인 버튼으로 조작하며, 결과를 신속하고 점진적이고 되돌릴 수 있게 표시하는 방식입니다. 단순히 노트와 비슷한 외관을 만드는 것만으로 사용하기 쉬워지지는 않습니다. [2011년 강의 노트, 13–14쪽](https://ocw.mit.edu/courses/6-831-user-interface-design-and-implementation-spring-2011/c74391b4bc3e58e025b317b61ef5a0ef_MIT6_831S11_lec02.pdf)
3. **Jakob Nielsen, Progressive Disclosure**: 중요한 옵션을 먼저 보여주고 드물거나 복잡한 옵션은 명확한 입구를 통해 펼치도록 합니다. 자주 쓰는 기능을 숨기거나 단계가 지나치게 깊어지지 않도록 주의해야 합니다. [NN/g 원문](https://www.nngroup.com/articles/progressive-disclosure/)
4. **Nielsen의 사용성 휴리스틱**: 현재 상태의 가시성, 사용자의 언어, 통제와 탈출구, 일관성, 기억보다 화면에서 알아보기, 불필요한 정보 줄이기를 참고했습니다. [2024년 검토판](https://www.nngroup.com/articles/ten-usability-heuristics/)

## 기존 화면에서 확인한 문제

| 문제 | 작업에 미치는 영향 | 적용한 변경 |
| --- | --- | --- |
| 생성 도구·복제·합산·축 설정이 같은 세로 목록에 있음 | 원하는 작업의 위치를 찾아 긴 목록을 훑어야 함 | 그리기는 캔버스 위, 도형 편집은 오른쪽, 축은 그래프 설정으로 분리 |
| 비활성 버튼까지 강조색으로 표시됨 | 현재 클릭이 선택인지 생성인지 구분하기 어려움 | 선택된 도구만 강조하고 캔버스 위에 현재 작업 표시 |
| 합산 패널의 열림 상태가 다른 도구와 독립적임 | 합산·복제·점 설정이 동시에 열려 혼동 | sumPanel을 다른 도구·복제와 배타적으로 관리 |
| 도형 설정이 모든 도구와 도형 목록 아래에 있음 | 선택한 뒤에도 편집 항목까지 스크롤해야 함 | 오른쪽 위에 현재 도형의 편집 항목을 바로 표시 |
| 기본 곡선의 생성 방향이 매번 바뀜 | 클릭 결과를 미리 예상하기 어려움 | 곡선 옆 메뉴에서 우하향·우상향을 명시적으로 선택 |
| 분류·곡률·접선 연결 옵션이 항상 펼쳐짐 | 이름 변경·간단한 형태 편집에도 많은 항목이 보임 | 세부 옵션을 이름이 있는 단일 펼침 영역으로 정리 |

## 현재 화면의 구조

- **상단 문서 작업**: 되돌리기/다시 실행, 배치, 그래프 설정, 저장(JSON 내보내기).
- **캔버스 위 그리기 도구**: 선택, 직선, 곡선, 점, 점선. 곡선의 기본 동작은 세 점으로 그리기이고 옆 메뉴에는 우상향·우하향 곡선을 둡니다. 합치기와 격자는 구분된 명령으로 둡니다.
- **오른쪽 위 편집 패널**: 빈 상태, 생성 중 옵션, 복제/합산, 선택한 도형 편집 중 하나만 표시합니다. 생성·복제·합산에는 닫기 버튼과 Esc가 같은 ‘선택으로 돌아가기’ 동작을 합니다.
- **오른쪽 아래 도형 목록**: 도형 선택과 폴더 관리를 한곳에 둡니다. 선택한 도형의 복제·삭제·이름은 편집 패널에 있습니다. 분류·휘어짐·직선에 접하기는 필요한 항목을 펼쳐서 봅니다.
- **그래프 설정**: 활성 그래프 이름, 사분면, 축 방향, 축 이름, 축 간격, 전체 삭제를 모읍니다. 입력은 즉시 반영되고 완료/닫기로 그림에 돌아갑니다. 배치는 별도 상단 버튼을 유지합니다.

그리기 자유도·수학 좌표·도형·접점 관계·되돌리기는 유지합니다. 이번 변경의 중심은 조작의 위치와 상태 표현이며, 기존 자유 곡선의 형태 생성 방식을 새로 설계하지 않았습니다. 사용하지 않는 비활성 자 버튼은 기본 화면에서 제외하고 보관 중인 자료·계산 코드는 유지합니다.

## 검증과 다음 판단 기준

개발자 검증은 ‘직선 추가 → 복제’, ‘복제 → 합산 → 점 전환’, ‘합산 완료 → 결과 편집’, ‘기본 곡선 추가’, ‘세 점 곡선 → 최저점 → 통과 직선’, ‘그래프 설정 → 캔버스로 복귀’를 실제 브라우저에서 수행했습니다. 한 번에 하나의 편집 문맥을 보여주는지, 작업 종료 후 선택 모드로 돌아오는지, JSON 좌표와 undo가 보존되는지 확인합니다.

이는 사용성 원칙을 적용한 구현과 개발자 검증입니다. 실제 사용자의 작업 시간을 측정한 비교 실험은 수행하지 않았습니다. 이후에는 원하는 기능을 찾는 데 걸리는 시간, 잘못된 도구로 그리는 횟수, 편집을 위해 스크롤하는 횟수, 취소·되돌리기 성공 여부를 보고 조정합니다. 특정 버튼 수나 레이아웃을 모든 사용자에게 보장되는 정답으로 보지는 않습니다.
