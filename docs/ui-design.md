# 화면 정리의 근거와 적용

## 2026-11-03 · 직각 쌍곡선

곡선 생성의 기존 ‘기본 곡선’ 목록에 그림과 이름이 있는 빠른 추가 버튼을 넣었습니다. 선택 편집에서는 기존 곡선 패널·손잡이·슬라이더를 재사용하되 ‘크기’로 표시해 휘어짐을 바꾸는 조작과 구분합니다. 직각 쌍곡선의 지수는 1로 유지하고 두 축을 점근선으로 고정합니다. 실제 추가·크기·몸체 드래그·단일 undo·복제를 확인했으며 화면 기록 도구 장애로 최신 스크린샷 저장/모바일 추가 검증은 완료하지 못했습니다. 사용자 대상 사용성 실험을 수행한 것은 아닙니다.

## 2026-11-03 · 복제 단순화

사용자 요청에 따라 세로축 절편 유지·기준점 선택·배치 선택과 ‘복제 옵션’ 펼침 메뉴를 제거했습니다. 대상·직선 기울기·미리보기·복제 버튼을 남기고, 하위 항목이 있는 경우에만 포함 여부를 직접 표시합니다. 기울기 변경은 현재 기준점을 사용하고 복사본은 자동으로 옆에 놓습니다. 조작 시간이나 학습 비용을 측정한 사용자 실험은 아닙니다.

## 2026-11-03 · 맞춤 UI 공통화

현재 구현·확장 기준은 [UI 공통 규칙](ui-consistency.md)에 정리했습니다. 점선에서 확인한 대상 강조·이중 원·짧은 맞춤 문구를 점·곡선 생성·직선/곡선 이동에도 적용했고, 도구별 SVG/CSS를 `snap-feedback.js/.css` 하나로 합쳤습니다. 자석 거리도 `snap-policy.js`의 16px 포착/24px 해제를 공유합니다. 곡선을 생성할 때의 접점 연결과 전체 도형 이동 중 일시적 맞춤은 기존 의미를 유지합니다.

모든 도구에서 같은 표시가 나오는지 계산된 스타일·원 크기·마커 개수·입력 통과와 취소/전환으로 검증했습니다. 실제 곡선 생성 미리보기·클릭 완성/관계/undo와 데스크톱/모바일도 확인했습니다. 조작 시간·학습 비용 개선을 측정한 사용자 실험은 아닙니다. [검증과 재현](testing.md)에 자동/합성 이벤트/실제 조작을 구분했습니다.

## 2026-11-02 · 영역 선택과 삭제

선택 도구에서 빈 공간을 끌어 영역을 만들고 영역에 닿는 도형/목록을 동시에 강조합니다. Ctrl/Cmd+클릭은 추가/해제, Shift+영역 드래그는 추가 선택입니다. 여러 선택에서는 개별 속성 입력을 숨기고 선택 목록·개수·삭제·선택 해제를 표시합니다. 도형 하나를 클릭하면 개별 이동/편집으로 돌아갑니다.

삭제는 작은 휴지통만 있던 개별 이름 옆 버튼에 **삭제** 글자를 붙이고, 도구막대에도 **삭제 / N개 삭제**를 둡니다. 여러 선택 패널에는 **선택한 N개 삭제**를 표시해 대상을 확인할 수 있게 합니다. Delete/Backspace는 입력란·IME·대화상자에서 도형을 지우지 않고, 키를 누른 채 생기는 반복 삭제도 생략합니다. 일괄 삭제는 한 번에 되돌립니다. 1280×800/390×844 화면과 실제 조작을 확인했으며 작업 시간/오류율 개선을 측정한 사용자 실험은 아닙니다.

2026-10-28. 사용자 목표는 경제 그래프를 노트처럼 자유롭게 그리는 것입니다. 기능이 늘어나면서 도구 탭과 설정이 뒤섞인다는 피드백에 따라 기존 기능의 진입점·배치·모드 표시를 정리했습니다. 아래 배치는 HCI 원칙을 이 프로젝트의 사용 흐름에 적용한 설계 판단입니다.

## 확인한 자료

1. **Ben Shneiderman, Designing the User Interface의 Eight Golden Rules**: 일관된 조작, 피드백, 오류 예방, 쉬운 되돌리기, 사용자의 통제, 기억 부담 감소를 강조합니다. [메릴랜드대학교의 저자 설명](https://www.cs.umd.edu/~ben/goldenrules.html)
2. **MIT 6.831/6.813, Learnability 강의**: 직접 조작은 대상을 계속 보여주고, 클릭·드래그·명시적인 버튼으로 조작하며, 결과를 신속하고 점진적이고 되돌릴 수 있게 표시하는 방식입니다. 단순히 노트와 비슷한 외관을 만드는 것만으로 사용하기 쉬워지지는 않습니다. [2011년 강의 노트, 13–14쪽](https://ocw.mit.edu/courses/6-831-user-interface-design-and-implementation-spring-2011/c74391b4bc3e58e025b317b61ef5a0ef_MIT6_831S11_lec02.pdf)
3. **Jakob Nielsen, Progressive Disclosure**: 중요한 옵션을 먼저 보여주고 드물거나 복잡한 옵션은 명확한 입구를 통해 펼치도록 합니다. 자주 쓰는 기능을 숨기거나 단계가 지나치게 깊어지지 않도록 주의해야 합니다. [NN/g 원문](https://www.nngroup.com/articles/progressive-disclosure/)
4. **Nielsen의 사용성 휴리스틱**: 현재 상태의 가시성, 사용자의 언어, 통제와 탈출구, 일관성, 기억보다 화면에서 알아보기, 불필요한 정보 줄이기를 참고했습니다. [2024년 검토판](https://www.nngroup.com/articles/ten-usability-heuristics/)

## 현재 화면의 구조

- **기존 점을 지나는 이동**: 사용자가 찍어 둔 점을 더 가까운 명시적 목표로 취급해 선/곡선 몸체 이동에서 붙입니다. 모양·점 위치를 유지하고 별도 명령이나 관계를 추가하지 않습니다. Shift는 잠긴 좌표를 지키며 Alt는 보정을 생략합니다. 피드백은 ‘점 맞춤’ 원과 짧은 글씨이고 기존 점 이름과 겹치지 않도록 아래에 표시합니다.
- **최신 절편·통일성 수정**: 직선 이동에 원점·기존 도형의 x/y절편 자석을 추가하고 점 생성도 같은 정확한 절편을 잡습니다. 축 띠로 획이 생략돼도 절편은 명확한 위치 대상으로 제공합니다. 곡선의 십자가+별도 원을 점 도구의 원형·좌표 포인터 하나로 통일합니다. 뜬금없는 작은 곡선 메뉴는 제거하고 곡선 그리기 패널에 방향 그림과 +가 있는 빠른 추가 버튼을 둡니다. 복제·합치기는 투명 배경·크기·글씨·여백·선택 상태를 같은 공통 규칙으로 맞춥니다.
- **곡선 이동 접선 보정**: 곡선 자체를 자유/Shift로 옮겨 직선에 붙이도록 기존 직접 조작을 확장합니다. 별도 가격효과 분해 모드나 보상예산선 명령을 추가하지 않습니다. 도형의 모양·원본을 유지하고 가까워지면 접점 피드백, 멀어지면 해제, Alt로 보정 생략을 사용합니다. 조작 의미를 사용자가 정한다는 제품 원칙을 유지합니다.
- **최신 추가 요청**: 복제 후 겹쳐 보이지 않게 기본 배치를 옆으로 띄우고 반복 사본의 같은 위치를 피합니다. Shift+드래그는 점선과 같은 수평/수직 이동 규칙을 사용하며 스냅도 잠긴 축을 존중합니다. 비직관적이라는 피드백을 받은 ‘직선에 접하기’ 수동 펼침 메뉴는 제거하고 직접 그리기·직선 이동의 자동 접선 보정을 유지합니다.
- **현재 작업 표시**: 선택한 도구만 강조합니다. 곡선 버튼을 누르면 그래프 안에 1/3 시작점→2/3 끝점→3/3 지나는 점을 표시하고 좌클릭·Esc를 같은 위치에 짧게 안내합니다. 시선을 오른쪽 패널로 옮기지 않아도 다음 행동을 알 수 있도록 하며 안내는 클릭을 가로채지 않습니다. 스냅 포인터에 접점·교점·절편의 종류를 표시합니다.
- **상단 문서 작업**: 되돌리기/다시 실행, 배치, 그래프 설정, 저장(JSON 내보내기).
- **캔버스 위 그리기 도구**: 선택, 직선, 곡선, 점, 점선. 곡선의 기본 동작은 세 점으로 그리기이고 방향이 정해진 기본 곡선은 생성 패널에서 그림 버튼으로 추가합니다. 복제·합치기는 같은 표현의 명령으로 두고 격자는 별도 표시 설정으로 둡니다.
- **오른쪽 위 편집 패널**: 빈 상태, 생성 중 옵션, 복제/합산, 선택한 도형 편집 중 하나만 표시합니다. 생성·복제·합산에는 닫기 버튼과 Esc가 같은 ‘선택으로 돌아가기’ 동작을 합니다.
- **오른쪽 아래 도형 목록**: 도형 선택과 폴더 관리를 한곳에 둡니다. 선택한 도형의 삭제·이름은 편집 패널에 있습니다. 복제는 10월 30일 가시성 개선 요청에 따라 캔버스 위 도구막대의 강조 버튼으로 이동했습니다. 분류·휘어짐은 필요한 항목을 펼쳐서 봅니다.
- **그래프 설정**: 활성 그래프 이름, 사분면, 축 방향, 축 이름, 축 간격, 전체 삭제를 모읍니다. 입력은 즉시 반영되고 완료/닫기로 그림에 돌아갑니다. 배치는 별도 상단 버튼을 유지합니다.

그리기 자유도·수학 좌표·도형·접점 관계·되돌리기는 유지합니다. 이번 변경의 중심은 조작의 위치와 상태 표현이며, 기존 자유 곡선의 형태 생성 방식을 새로 설계하지 않았습니다. 사용하지 않는 비활성 자 버튼은 기본 화면에서 제외하고 보관 중인 자료·계산 코드는 유지합니다.

## 검증과 다음 판단 기준

개발자 검증은 ‘직선 추가 → 복제’, ‘복제 → 합산 → 점 전환’, ‘합산 완료 → 결과 편집’, ‘기본 곡선 추가’, ‘세 점 곡선 → 최저점 → 통과 직선’, ‘그래프 설정 → 캔버스로 복귀’를 실제 브라우저에서 수행했습니다. 한 번에 하나의 편집 문맥을 보여주는지, 작업 종료 후 선택 모드로 돌아오는지, JSON 좌표와 undo가 보존되는지 확인합니다.

이는 사용성 원칙을 적용한 구현과 개발자 검증입니다. 실제 사용자의 작업 시간을 측정한 비교 실험은 수행하지 않았습니다. 이후에는 원하는 기능을 찾는 데 걸리는 시간, 잘못된 도구로 그리는 횟수, 편집을 위해 스크롤하는 횟수, 취소·되돌리기 성공 여부를 보고 조정합니다. 특정 버튼 수나 레이아웃을 모든 사용자에게 보장되는 정답으로 보지는 않습니다.
