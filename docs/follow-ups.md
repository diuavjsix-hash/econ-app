# 후속 작업 · 직선/점선 끝 정리

정리: 2026-11-07. 직선 끝 자르기·점선 스타일(schemaVersion 11)을 구현한 뒤 남은 세 가지입니다. 아직 아무것도 구현하지 않았습니다. 사용자와 합의한 순서는 **1 → 2 → 3(결정)**입니다. 시작 전에 [HANDOFF](../HANDOFF.md), [구조 문서](architecture.md)의 '직선 끝 자르기·점선 스타일', [공통 UI 규칙](ui-consistency.md)을 확인하고 최신 사용자 지시를 우선합니다.

용어 주의: 여기서 '통일'은 툴바의 **합치기(수직합·수평합)**와 무관합니다.

## 1. 점선 끝점을 끝점 맞춤 대상으로 등록

**상태:** 권장, 미착수. 자유 곡선의 시작점·끝점까지 함께 넣을지는 사용자에게 확인합니다(선택 사항).

**왜:** 잘린 직선의 끝은 `kind:'endpoint'`(**끝점 맞춤**) 대상인데 점선 도구 선분의 끝은 아닙니다. 같은 '끝'이 도구에 따라 다르게 동작합니다. 점에서 축까지 내린 점선 끝에서 다른 선을 잇는 일이 잦습니다.

**방법:**
- `src/graph/snap.js`의 `buildSnapTargets`에서 잘린 직선 끝을 등록하는 반복문 옆에 `state.dashedLines`의 `anchor`·`end`를 같은 형태(`{point, ids:[id], sourceId:id, kind:'endpoint', label:'끝점 맞춤'}`)로 추가합니다. 화면 밖은 `isLinePointVisible`로 제외합니다.
- 새 문구·표시를 만들지 않습니다. `snap-feedback.js`에 `endpoint` 기본 문구가 이미 있습니다.
- 자기 점선을 편집하는 동안의 제외는 `independentSnapState`가 처리합니다. 캐시 키(`geometryKey`)는 점선 좌표를 이미 포함합니다.

**검증(AGENTS 규칙):**
- 점선 끝에 맞춘 뒤 조작을 끝내고, 점 생성/이동·점선 생성/끝점/전체 이동·직선 끝 드래그·곡선 시작/끝점에서 다시 잡히는지 확인합니다.
- Shift·Alt·축 반전·312px·되돌리기를 함께 확인합니다.
- 기존 점선 검사(`tests/dashed*.test.js`, `tests/browser/dashed-curve-contact.html`, `snap-feedback.html`)에서 '선 맞춤'이 '끝점 맞춤'으로 바뀌는 곳이 있을 수 있습니다. 위치가 같고 이름만 정확해진 경우인지 확인한 뒤 고칩니다.

## 2. 잘린 직선 전체 이동 때 잘린 끝도 맞춤

**상태:** 권장, 1번 다음.

**왜:** 점선은 몸통을 옮길 때 양 끝 중 하나가 대상에 붙습니다(`snapMovingDashed`). 잘린 직선은 직선 자체 자석(절편·접선·점 통과)만 동작합니다. 꺾인 선의 한쪽을 옮겨 다른 끝에 다시 붙이거나, 선분 끝을 축에 맞추려면 필요합니다.

**방법:**
- `src/graph/intercepts.js`의 `snapMovingLine`에서 잘린(값이 있는) 끝마다 `snapMovingDashed`와 같은 방식으로 '끝이 대상에 닿도록 하는 평행이동' 후보를 만듭니다.
- 이 후보를 기존 후보들과 함께 `chooseShapeMagnet`으로 고릅니다. 열린 끝(null)은 후보가 없습니다.
- 결과의 `anchor`를 기존과 같이 돌려주면 extent는 평행이동이라 그대로 유지됩니다.
- 합의할 규칙: 직선 자석('직선이 점을 지나게')과 끝 자석('끝이 점에 닿게')이 동시에 걸리면 공통 정책대로 더 가까운 쪽이 이깁니다. 다르게 하려면 사용자에게 먼저 묻습니다.
- 점을 따라가는 직선은 몸통 이동이 막혀 있으므로 대상이 아닙니다.

**검증:**
- 끝이 교점·절편·점·접점·다른 끝에 붙는지, Shift 축 고정, Alt, 24px 유지를 확인합니다.
- 직선 자석과 경쟁하는 경우, 되돌리기 한 번, 놓은 뒤 다른 도구의 재포착도 확인합니다.
- `tests/line-extent.test.js`와 `tests/browser/line-extent.html`에 사례를 추가합니다.

## 3. 점선 도구 선분과 직선 도형 통일 (결정 필요)

**상태:** 1·2번 이후에 할지 결정합니다. 지금은 하지 않습니다.

**의미:** 점선 도구가 '양 끝이 잘린 점선 스타일 직선(`lines`)'을 만들고, `dashedLines` 도형 종류를 없애는 것입니다. 그러면 점선 보조선도 선택하면 직선 설정이 나오고, 실선 전환·반직선 연장·회전이 가능해집니다.

**판단 기준:** 1·2번 이후에도 사용자가 두 도형을 다르게 느끼는 점이 남아 있는가.

**옮겨야 할 점선 전용 동작:**
- 수평/수직/자유 생성 모드와 Shift 고정(생성 방식이므로 도구에 남김)
- `dashedSnap` 마우스 보정 켜기/끄기
- 끝점 손잡이 편집
- 몸통 이동 끝 맞춤(2번에서 해결)

**정해야 할 UI:** 짧은 보조선을 선택했을 때 기울기 슬라이더·식이 번잡하지 않은지 봐야 합니다. 필요하면 양 끝이 잘린 점선은 간단한 설정만 보이게 합니다.

- 출력 형식은 schemaVersion을 올리고 `dashedLines`를 없애거나 빈 배열로 둘지 정합니다.
