# 후속 작업 · 직선/점선 정리 (완료)

정리: 2026-11-08. 시작 전에 [HANDOFF](../HANDOFF.md), [구조 문서](architecture.md)의 '두 점 직선 도구', [공통 UI 규칙](ui-consistency.md)을 확인하고 최신 사용자 지시를 우선합니다.

용어 주의: 여기서 '통합'은 툴바의 **합치기(수직합·수평합)**와 무관합니다.

## 완료 (2026-11-08)

- 직선 도구: 두 점으로 직선·반직선·선분과 실선·점선을 그림. 선택한 직선도 같은 버튼으로 변경.
- 툴바의 **점선** 버튼과 점선 패널 제거. 사용자는 직선 도구의 "선분 + 점선"으로 같은 선을 그림.
- 끝 손잡이로 직선을 자르거나 다시 이어 붙이는 동작 제거. 손잡이는 그려진 끝에만 있고 그 끝을 옮기기만 함.
- 모든 생성·복제 뒤 선택 도구로 돌아가고 결과를 선택.

## 완료 (2026-11-08, 세 번째 요청)

- 선분·반직선 전체 이동 때 그려진 끝 맞춤(`snapLineEnds`/`snapMovingEnds`).
- 내부 점선 도형(`dashedLines`)·`dashed` 모드·`DashedCreation`·`snapMovingDashed` 제거, schemaVersion 12, 공통 계약 검사를 직선 도구 선분으로 이전.
- 자유 곡선 시작점·끝점의 **끝점 맞춤** 등록(사용자 확인 완료).

남은 후속 작업은 없습니다.

## 제안만 해 둔 것 (2026-11-12, 사용자 요청 시 진행)

아래는 구현하지 않았고 사용자가 고르지 않은 항목입니다. 먼저 제안하지 말고 요청이 있을 때 진행합니다.

- **여러 그래프 배치 다시 구현:** 2026-11-13에 불안정해서 지웠습니다(그래프 1개만 남김). 이전 배치·연결선 구현은 `v10` 태그에 있습니다([구조 문서](architecture.md#여러-그래프-배치연결선-제거-2026-11-13)).
- **대면 포맷 맞은편의 곡선 종류:** 무차별곡선·PPC 등은 양의 영역에만 그려집니다.
- **그린 뒤 색 고르기:** 직선은 실선이면 순서대로 돌아가는 색, 점선이면 회색으로만 정해집니다(같은 대화에서 곡선 기본색 문제도 보류됨).

## 이미 정해진 것 (다시 묻지 않음)

- 선 종류(직선·반직선·선분)는 설정 버튼으로만 바꿉니다. 끝 손잡이는 그려진 끝에만 있고, 끌어도 끝이 열리거나 닫히지 않으며 화면 밖으로 나가지 않습니다.
- 모든 생성·복제 뒤에는 선택 도구로 돌아가고 결과를 선택합니다. 도구에서 고른 종류·모양 같은 설정은 다음에도 유지됩니다.
- 잘린 직선: 이동은 길이 유지, 회전은 중심에서 끝까지 거리 유지, 잘린 끝은 맞춤 대상, 합치기(합산)에서 제외.
- 로컬 검증만 하고, 사용자 요청 없이 커밋·푸시하지 않습니다.
