# 무차별곡선 모음

2026-11-03에는 기본 곡선 목록에 **직각 쌍곡선**을 추가했습니다. 내부에서는 아래 기하·이동·자석 코드를 재사용하며 `family:'rectangular-hyperbola'`로 구분합니다. `xy=anchor.x*anchor.y`의 양수 가지이고 두 축을 점근선으로 유지합니다. 몸체·크기 손잡이·슬라이더는 원점 기준 크기만 바꾸고 지수는 1로 고정합니다. 음수 가지·점근선 이동·합산은 제공하지 않습니다. 내부 공통 모듈을 사용한다는 이유로 도형에 경제적 역할이나 새 관계를 부여하지 않습니다.

2026-11-02 사용자 요청에 따라 곡선 패널에 콥더글라스·완전대체재·완전보완재·준선형효용을 추가했습니다. 사용자는 함수식 대신 몸체 이동·모양 손잡이·슬라이더·복제로 그림을 구성합니다. 기존 세 점 자유 곡선과 기본 곡선도 유지합니다.

## 조작

| 종류 | 몸체 드래그·방향키·옆 복제 | 모양 조절 |
| --- | --- | --- |
| 콥더글라스 | 원점을 고정해 확대·축소 | 휘어짐 |
| 완전대체재 | 기울기를 유지한 평행이동 | 기울기 |
| 완전보완재 | 꺾임을 원점에서 뻗는 같은 반직선 위로 이동 | 꺾임의 가로·세로 비율 |
| 준선형효용 | 기본 y축, 선택 시 x축으로 평행이동 | 휘어짐과 선형 축 선택 |

모양 조절은 선택 도형의 선호 형태를 바꿉니다. 같은 선호의 다른 수준을 그리려면 먼저 복제하고 몸체만 이동합니다. 사본은 독립 객체이므로 원본의 모양을 나중에 바꿔도 사본에 자동 반영하지 않습니다. 반전된 좌표축에서도 내부 수학 좌표의 원점·선형 축을 기준으로 움직입니다. 무차별곡선에서는 고유 이동 규칙이 Shift 축 제한보다 우선하며, 완전대체재는 Shift 이동량을 해당 축으로 제한한 뒤 같은 평행 직선으로 표현합니다. Alt는 자석만 생략하고 이동 규칙은 유지합니다.

콥더글라스·완전보완재의 몸체 드래그는 잡은 위치의 원점 반직선에 포인터를 투영해 배율을 정합니다. 가운데 점이 아닌 곡선 몸체를 잡아도 드래그 시작 시 그림이 뛰지 않습니다. 두 기준점 좌표의 최소값을 0.02로 제한해 원점을 넘거나 0 크기로 붕괴하지 않게 합니다. 완전대체재는 같은 직선 위의 불필요한 기준점 이동을 제거하고 양의 절편을 유지합니다. 준선형의 축 전환은 두 기준 좌표를 맞바꾸어 전체 곡선을 반사합니다.

## 직선·점 맞춤

같은 그래프의 직선과 기존 점을 대상으로 공통 16px 포착·24px 유지/해제·Alt 생략·단일 undo를 공유합니다. 기존 점은 그대로 두고 도형 수준만 바꾸며 새 binding을 만들지 않습니다. 대상 강조·이중 원·문구는 공통 맞춤 UI를 사용합니다.

- 콥더글라스는 직선의 현재 기울기에 맞는 미분 접점을 찾고, 원점 기준 배율만 바꿔 그 직선에 접하게 합니다.
- 준선형은 기울기에 맞는 접점을 찾고, 선형 축 좌표만 바꿔 맞춥니다. 같은 직선 기울기에서 선형 축 방향으로 수준이 달라져도 비선형 축의 접점 좌표는 유지됩니다.
- 완전보완재는 우하향 직선이 꺾임을 지지하도록 맞추고 **꺾임 맞춤**을 표시합니다.
- 완전대체재는 같은 기울기에서 평행 직선을 겹칩니다. 서로 다른 우하향 기울기에서는 비음수 소비 영역의 적절한 축 위 모서리에 맞추고 **모서리 맞춤**을 표시합니다. 예산선 기울기의 절댓값이 곡선 기울기의 절댓값보다 작으면 x축 모서리, 크면 y축 모서리를 사용합니다.

직선을 곡선으로 이동할 때도 같은 정확한 접점·꺾임·모서리를 사용합니다. 수직·수평·우상향 직선에는 새 경제적 최적점을 만들지 않습니다. 축 간격에 가려진 지지점과 화면 밖 지지점에는 자동으로 붙지 않습니다. Alt로 자유 배치하거나 축 간격을 끈 뒤 직접 점을 찍을 수 있습니다.

보상예산선은 기존 직선을 복제해 기울기를 바꾼 다음 원래 무차별곡선으로 이동하는 방식으로 직접 구성합니다. 다른 수준의 곡선도 복제 후 새 직선에 맞출 수 있습니다. 가격효과의 수치 계산·자동 분해·전용 모드·소득/가격 입력·새 따라가기 관계는 추가하지 않았습니다. 준선형의 경계해와 모든 일반적인 소비자 최적화를 자동으로 푸는 기능은 아닙니다.

## 내부 기하와 저장

`src/graph/indifference.js`에서 계산하고 기존 `curves` 컬렉션에 `type:'curve'`와 `family` 구분으로 저장합니다. 새 컬렉션을 만들지 않아 그래프 전환·숨김 배치·계층·삭제·전체 삭제·기록을 함께 사용합니다. 버전 9에서 도입하고 현재 JSON 10에서도 `family`, `anchor`, `shape`, 준선형의 `linearAxis`, `geometry.type='indifference'`를 기록합니다. 기존 기본 곡선의 이차식·접선 연장 자료로 위장해 출력하지 않습니다.

구현 내부에서 기준점 `(a,b)`를 지나는 곡선을 다음처럼 평가합니다. 아래 식은 구현 명세이며 제품 입력 UI에는 표시하지 않습니다.

| family | 내부 기하 |
| --- | --- |
| `rectangular-hyperbola` | `y = a*b/x`, x,y > 0; `shape`는 1 고정 |
| `cobb-douglas` | `y = b (a/x)^shape`, x,y > 0 |
| `substitutes` | `y = b - shape (x-a)`, x,y ≥ 0 |
| `complements` | `(a,b)`에서 위쪽과 오른쪽으로 나가는 정확한 두 반직선 |
| `quasilinear`, y 선형 | `y = b - shape log(x/a)`, x > 0, y ≥ 0 |
| `quasilinear`, x 선형 | `x = a - shape log(y/b)`, y > 0, x ≥ 0 |

준선형은 조절 가능한 로그형 도식을 사용하며 임의의 비선형 함수를 입력하는 도구는 아닙니다. `shape` 범위는 0.15~20이고 완전보완재는 이 값을 기하 평가에 사용하지 않으며 꺾임 좌표의 비율로 형태를 정합니다. 선형 축의 기준 좌표는 음수가 될 수 있지만 실제 곡선은 비음수 소비 영역만 표시합니다.

표시는 수학 좌표 중점 오차 0.0005, 최대 깊이 18의 적응형 직선 조각을 기존 SVG 이차 경로 인터페이스로 전달합니다. 화면 픽셀이나 이 표시 근사는 저장하지 않습니다. 접점과 직선 교점은 원본 함수에서 계산하고, 매끄러운 곡선의 직선 교점은 유일한 극값으로 구간을 나눈 뒤 이분법으로 계산해 두 교점과 중근 접점을 구분합니다. 일반 선 위 최근접점과 곡선끼리의 교점은 표시 근사를 사용합니다. 극단적인 수치에서는 깊이 제한 때문에 오차 상한을 보장하지 않습니다.

옆 복제는 종류별 이동을 지키며 반복 사본을 띄웁니다. 폴더에 무차별곡선을 넣어 복제할 때도 각 곡선의 이동 규칙이 우선하므로 다른 하위 도형과 공통 평행이동량을 보장하지 않습니다. 무차별곡선은 기존 기본 곡선 전용 합산에서 제외합니다.

경제적 형태 검토에는 [UCL 소비자이론 강의 노트](https://www.ucl.ac.uk/~uctp100/2001/2001notes.pdf), [Nechyba 교재의 선호 형태 그림](https://econweb.com/NechybaMicro/Ch5_animated.html)을 참고했습니다. 조작 방식과 자석·저장 설계는 이 앱의 구현 선택입니다.
