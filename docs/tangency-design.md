# 자유 곡선·접점 설계

최종 정리: 2026-11-04. 현재 목표는 **수식 입력 없이 노트처럼 자유롭게 그리기**입니다. 이 문서는 실제 구현을 설명합니다. 경제 모형 프리셋·일반 곡선끼리 제약·3차 베지어를 검토했던 [초기 제안](history/tangency-proposal.md)은 이력으로 분리했습니다.

## 현재 선택한 방식

사용자 원칙은 기존 그리기·복제·이동을 자유롭게 조합하는 것입니다. 가격효과 분해 등 특정 모형의 전용 조작을 추가하지 않습니다. 곡선을 직접 옮기는 접선 자석은 모양을 유지하는 임시 위치 보정이며, 경제적 의미·영구 연결·자동 변형을 부여하지 않습니다.

| 사용자 조작 | 구현 |
| --- | --- |
| 시작점·끝점·지나는 점을 찍기 | 두 이차 베지어 구간이 세 점을 정확히 통과 |
| 가운데에서 방향을 바꾸기 | 두 구간 제어점을 가운데 접선 방향에 배치 |
| 한쪽만 더 휘게 만들기 | leftReach/rightReach로 양쪽 제어점 거리를 독립 조절 |
| 세 번째 점을 직선 근처에 찍기 | 가운데 점을 직선에 투영하고 접선 방향 공유; 수동 접하기 메뉴는 제거 |
| 직선을 곡선에 가까이 이동 | 기울기를 유지하며 접선 위치로 자석 보정; 새 binding은 만들지 않음 |
| 곡선을 직선에 가까이 이동 | 양쪽 구간에서 직선의 현재 기울기에 맞는 접점을 찾아 전체 평행이동; 자유/Shift 이동·Alt 생략 |
| 곡선을 다른 곡선에 가까이 이동 | 원본 기하에서 공통 접선 방향의 접촉점을 찾아 허용 이동으로 보정; 공통 표시·Shift/Alt·단일 undo |
| 접한 두 곡선의 접점에 점/점선 배치 | 이동과 같은 원본 기하로 접점을 복원해 공통 목록에 등록; 점 생성/이동·점선 생성/끝점/전체 이동에 공유 |
| 직선·곡선을 찍어 둔 점에 가까이 이동 | 그 점을 정확히 지나도록 전체 평행이동; 점 위치·도형 모양 유지, 새 binding 없음 |
| 접점 계속 유지 | 직선 참조·거리·마지막 방향을 binding에 저장 |
| 최저점 표시 | 유한 곡선 전체의 끝점·y 극값 후보를 비교 |
| 최저점을 지나는 선 | 곡선→최저점→직선의 단방향 따라가기 |
| 다시 자유 편집 | 연결만 해제하고 현재 좌표·형태 유지 |

기존 단조 `curve`의 뜻을 유지하기 위해 `sketch`를 별도 타입으로 추가했습니다. 자유 곡선은 ∪/∩/⊂/⊃ 같은 초기 모양과 직접 편집을 제공하며, 시작점~끝점 사이에만 표시합니다. 현재 경제 함수나 균형 계산은 요구하지 않습니다.

## 기하

start=S, 가운데 anchor=T, end=E, 단위 tangent=d라 할 때 제어점은 다음과 같습니다.

```text
왼쪽: [S, T − d × |S−T| × leftReach, T]
오른쪽: [T, T + d × |E−T| × rightReach, E]
```

두 구간은 T에서 같은 접선 방향을 가집니다. 양쪽 reach가 독립적이므로 매개변수 미분 크기까지 일치하는 C1 연속성을 강제하지 않습니다. 두 점의 중복·비유한 좌표·제어점 오버플로는 거절하며 reach 범위는 0.05~2입니다.

접선 방향은 위치나 기울기 숫자 하나로 표현하지 않고 벡터로 저장하므로 수직 방향도 지원합니다. 직선에 연결된 경우 기울기 null도 정확히 처리합니다. 직선의 정규화 방향이 수직 회전 경계에서 뒤집히면 저장 거리를 함께 뒤집어 접점이 반대편으로 튀지 않게 합니다.

## 관계와 편집

관계는 같은 그래프의 객체만 참조합니다. 직선→자유 곡선→최저점→통과 직선처럼 의존 관계를 먼저 계산하고, 원래 자유 곡선을 그 통과 직선에 다시 연결하려는 순환은 거절합니다. 목록 계층 parentId와 계산 관계는 독립적입니다.

직선 이동·회전 시 연결된 가운데 점과 접선 방향을 갱신합니다. 시작점·끝점은 독립 좌표를 유지합니다. 연결 중 가운데 점·전체 이동은 직선을 따라 움직이고, 접선 방향 변경·모양 프리셋은 연결 해제 후 사용합니다. 최저점·통과 직선의 직접 이동도 연결 해제 후 가능합니다. 통과 직선의 기울기는 연결 중에 바꿀 수 있습니다.

원본 삭제는 종속 도형을 현재 기하로 남기고 관계만 끊습니다. 복제는 관계를 끊은 독립 사본입니다. 생성·관계·삭제·복제·드래그는 undo/redo 대상이며 화면 크기·축 반전·축 간격은 원본 좌표를 바꾸지 않습니다.

## 보장 범위와 제한

- 곡선 이동 보정은 실제 곡선 안에 해당 방향의 접선이 있고 허용 이동 방향으로 도달할 수 있을 때 적용합니다. 원래 가운데 접점에 국한하지 않지만 자유 곡선 끝을 임의로 연장하거나 휘어짐을 바꾸지는 않습니다. 연결된 곡선은 연결 해제 또는 독립 복제 후 다른 직선에 자유롭게 맞춥니다.
- 기존 점 맞춤은 직선·기본 곡선·독립 자유 곡선의 몸체 이동에 적용합니다. 자유 이동은 정확한 최근접점, Shift는 잠긴 좌표와 곡선의 교차를 사용합니다. 공통 16px 포착·24px 해제·Alt 생략을 공유하며 더 가까운 명시적 점은 잡혀 있던 절편·접선 후보에서 이어받을 수 있습니다. 자기 도형에 종속된 점은 제외하고 새 연결은 만들지 않습니다.
- 접점은 공통 위치와 접선 방향을 보장합니다. 곡선이 직선의 한쪽에만 놓이는지, 경제적으로 최적인지, 단조인지까지 자동 검증하지 않습니다. 자유로운 도식의 의미는 사용자가 정합니다.
- 최저점은 현재 유한 곡선의 전역 최저점이며 내부 지점일 필요는 없습니다. 화면 밖이거나 숨긴 구간에 있을 수 있고, 끝점 또는 여러 같은 높이 후보 중 하나일 수 있습니다.
- 자유 곡선끼리의 직접 접점 연결, 기본 curve의 최저점 명령, 자유 곡선의 수직/수평합과 경제 모형 최적화는 미지원입니다.
- 곡선끼리 몸체 이동 자석은 영구 연결 없이 동작합니다. 기본/자유 곡선은 평행이동하고 PPC·무차별곡선은 기존 원점 확대/축소 또는 축 이동을 유지합니다. 단순 교차·전체 겹침·L자 꺾임과 허용 이동으로 도달할 수 없는 접점은 제외합니다. 유한한 접선 방향 탐색으로 극도로 좁거나 특이한 해를 놓칠 수 있습니다.
- 표시·일반 선 위 스냅은 적응형 선분 근사를 공유합니다. 직선과 자유 곡선의 교점·접점, 전체 이동의 접선/점 맞춤과 최저점·접점 관계는 원본 기하를 사용합니다. 대량 도형 성능·극단 수치에서의 표시 오차 상한은 보장하지 않습니다.

## 후속 작업 판단

현재 사용자의 실제 편집에서 필요한 조작을 확인하며 자유도와 발견 가능성을 조정합니다. 수식 기반 경제 모형은 추후 명시적 요청이 있을 때 별도 범위로 검토합니다. 곡선끼리 이동 자석은 대상 고정·현재 이동 제약·해가 없으면 보정 생략을 따릅니다. 향후 영구 접점 관계를 요청받으면 고정 도형·허용 이동·해가 없는 경우·관계 순환을 별도로 정의해야 합니다.
