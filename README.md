# Econ Studio

여러 경제 그래프를 배치하고 직접 그려보는 웹 작업 공간입니다. 직선, 우상향·우하향 곡선, 이름 있는 점과 점선을 그리고 도형을 폴더처럼 정리할 수 있습니다. 좌표축 이름 편집, 마우스 이동·형태 조절, JSON 출력을 지원합니다.

개발을 이어받으실 때는 [작업 인계](HANDOFF.md)를 먼저 읽어 주세요. 앱 소스·문서·테스트·실행 스크립트는 이 저장소에서 함께 관리합니다. [구조 문서](docs/architecture.md)와 [JSON 형식](docs/json-format.md)에 구현 기준을 정리했습니다.

## 로컬 실행

Windows에서는 프로젝트 폴더의 **`server.cmd`를 더블클릭**하면 서버 메뉴가 열립니다.

| 메뉴 | 동작 |
| --- | --- |
| `1` · Start / Open browser | 서버를 백그라운드에서 켜고 브라우저를 엽니다. 이미 켜져 있으면 기존 서버를 사용합니다. |
| `2` · Stop | 이 메뉴나 시작 파일로 실행한 서버를 종료합니다. |
| `3` · Status | 실행 여부와 주소를 확인합니다. |
| `0` · Exit menu | 메뉴만 닫습니다. 서버는 계속 실행됩니다. |

**`start-server.cmd`**는 서버 시작, **`stop-server.cmd`**는 서버 종료를 바로 실행합니다. 파일은 다른 작업 폴더에서 실행해도 동작합니다. PATH의 Node.js 20 이상을 먼저 찾고, 없으면 현재 컴퓨터의 Codex 번들 Node 경로를 자동 확인합니다. 직접 경로를 지정하려면 `ECON_NODE` 환경 변수를 설정합니다.

포트를 바꾸거나 터미널에서 상태를 확인할 수도 있습니다.

```powershell
.\start-server.cmd -Port 5174
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\server.ps1 -Action status
.\stop-server.cmd
```

브라우저를 열지 않고 실행하려면 `start-server.cmd -NoBrowser`를 사용합니다. 사용 중인 포트는 오류로 안내하며 기존 프로그램을 종료하지 않습니다. 다른 데스크톱의 세 .cmd 실행 파일에 기기 전용 수정본과 skip-worktree 설정이 있는 경우 이를 유지하고 GitHub에 올리지 않습니다. 현재 실행 파일은 저장소에서 삭제하지 않습니다.

서버 기록과 로그는 Git에서 제외된 `.local/server.json`, `.local/server.stdout.log`, `.local/server.stderr.log`에 보관합니다. 아래의 직접 Node 실행 방식으로 켠 서버는 해당 터미널의 Ctrl+C로 종료합니다.

Node.js 20 이상에서 별도의 의존성 설치 없이 실행합니다.

```sh
node scripts/dev-server.mjs
```

현재 컴퓨터의 일반 PowerShell에서 `node`를 찾지 못하면, Codex에 포함된 실행 파일을 직접 사용합니다. 아래 경로의 Node.js 24.22.1 실행을 확인했습니다.

```powershell
cd "C:\Users\htt06\OneDrive\바탕 화면\econ-app"
& "C:\Users\htt06\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin\node.exe" scripts/dev-server.mjs
```

이 경로는 현재 컴퓨터의 Codex 런타임 경로입니다. 다른 환경에서는 Node.js 20 이상을 준비한 뒤 `node` 명령을 사용합니다. 서버를 종료할 때는 실행한 PowerShell 창에서 Ctrl+C를 누릅니다. `EADDRINUSE` 오류는 이미 같은 포트의 서버가 실행 중이라는 뜻입니다.

브라우저에서 http://127.0.0.1:5173 에 접속합니다.

- **직선 +** 버튼을 누를 때마다 새 직선을 추가합니다.
- **곡선 +** 버튼은 우하향·우상향 곡선을 번갈아 추가합니다. 선택 후 **우상향 / 우하향** 버튼으로 방향을 바꿀 수 있습니다. 이름은 방향 변경과 별도로 유지됩니다.
- 곡선은 드래그로 이동하고, **휘어짐** 슬라이더 또는 곡선 위 흰색 점의 위아래 드래그로 곡률을 조절합니다. 0%는 직선 형태이며, 최대 휘어짐에서도 각 방향을 유지합니다.
- 곡선 양 끝은 끝점의 기울기를 따라 축이나 작업 영역 경계까지 이어 표시합니다. 추가하거나 이동했을 때 화면 중간에서 짧게 끊기지 않으며, 이어진 부분도 드래그할 수 있습니다.
- 오른쪽 **축** 영역에서 수평축·수직축의 이름을 입력합니다. 입력 즉시 화면과 JSON에 반영됩니다. 이름을 비우면 해당 축의 이름만 숨깁니다.
- **축에서 선 띄우기**를 켜면 직선·곡선이 축에서 일정 간격을 두고 표시됩니다. 기본 간격은 0.75이며 0.25~2 좌표 단위로 조절합니다. 그래프마다 따로 적용하며 원본 좌표·기울기·점·점선은 바꾸지 않습니다. 숨긴 구간에는 마우스가 붙지 않습니다.
- 처음 열리는 **작업 영역** 창에서 배치와 사분면을 고르고 **시작**을 누릅니다. 가로·세로 2개/3개, **ㄴ자 3개**(위 왼쪽 하나, 아래 두 개), **좌우 대면 / 상하 대면**, 격자 4개를 제공합니다. **직접 배치**에서는 3×3 칸을 눌러 최대 9개까지 배치할 수 있습니다. 상단 **배치 · N개**로 나중에 변경합니다. 적용 전 선택은 문서를 바꾸지 않으며, 이후에는 닫기나 Esc로 취소합니다.
- 그래프 제목이나 평면을 누르면 그 그래프가 선택됩니다. 오른쪽 도구·도형 목록·축 이름·격자 버튼·도형 전체 삭제는 **선택한 그래프**에 적용합니다. 그래프마다 이름, 사분면, 축 이름, 선·곡선·점·폴더가 독립적입니다. 도형 계층과 마우스 보정도 같은 그래프 안에서 동작합니다.
- 오른쪽 **선택한 그래프**의 **x 증가 / y 증가**로 축을 좌우·상하 반전합니다. 좌우 대면은 왼쪽 그래프의 x축이 왼쪽으로, 상하 대면은 아래 그래프의 y축이 아래로 증가합니다. 도형·점·점선·마우스 좌표·방향키 이동이 함께 반영되며 내부 좌표와 기울기는 보존됩니다. 반전된 화면에서는 우상향·우하향의 시각 방향도 달라집니다.
- 오른쪽 **사분면**은 선택한 그래프만 바꿉니다. 작업 영역 창에서 **모든 그래프에 적용**을 켜면 현재 배치에 표시되는 그래프에 함께 적용합니다. 배치를 줄이면 남는 그래프는 삭제하지 않고 보관하며, 배치를 다시 늘리면 기존 순서대로 나타납니다. 배치 프리셋을 변경하면 표시되는 그래프의 축 방향은 해당 프리셋으로 설정합니다. 이름·도형 좌표·축 이름은 유지합니다.
- 좁은 화면에서는 그래프 영역 안을 가로·세로로 스크롤합니다. 가로 배치나 ㄴ자 배치를 세로 목록으로 바꾸지 않습니다. 그래프 사이의 공통 축·변수 연동·연결선은 아직 지원하지 않습니다.
- **손**은 기본 선택 도구입니다. 그래프에 아무것도 추가하지 않고 기존 도형을 좌클릭해 선택·드래그·키보드 이동합니다. 빈 평면이나 그래프 제목을 누르면 도형 선택을 해제합니다. Esc로 손 모드에 돌아갑니다.
- **점**에서 **점 생성**은 기본 ON이며 그래프 **좌클릭**으로 점을 만듭니다. 기존 선·곡선 위를 눌러도 보정된 위치에 점을 생성합니다. 우클릭은 점을 만들지 않습니다. 도형을 선택·이동하려면 **손**을 사용합니다. 점 탭의 점선 포인터·현재 좌표·마우스 보정·좌표 표시 옵션과 생성 ON/OFF 선택은 탭 전환 뒤에도 유지합니다.
- **마우스 조정**은 기본으로 켜져 있으며 가까운 직선·곡선·축·점선 선분에 붙는 기능을 켜고 끕니다. 교점은 더 넓은 범위에서 우선 잡히며 ‘교점’과 정확한 좌표를 표시합니다. 좌클릭 생성·점 드래그에도 같은 보정을 적용합니다. 떨어진 곳에서는 자유롭게 움직이고 Alt를 누르면 일시적으로 보정을 생략합니다. 조정을 꺼도 점 탭이 선택되어 있으면 원과 좌표는 유지됩니다. 그래프를 벗어나면 표시를 숨깁니다. 방향키 이동은 보정하지 않습니다. 선을 나중에 움직여도 점은 기존 좌표에 남습니다.
- **좌표 함께 표시**를 켜면 새 점에 `(x, y)` 좌표를 함께 표시합니다. 표시값은 소수 둘째 자리까지 반올림하며 점 이동에 따라 갱신됩니다. 기존 점은 점 설정의 **좌표 표시**로 따로 켜고 끕니다. 내부 좌표와 JSON은 원래 정밀도를 유지합니다.
- 선택한 항목의 **이름**을 입력하면 목록에 반영됩니다. 점의 이름은 그래프에도 표시됩니다. 점 선택 설정에는 **좌표 표시**만 제공합니다. 점에 자동으로 붙는 보조선 기능은 제거했습니다.
- **점선** 탭에서 두 곳을 차례로 클릭하거나 드래그하면 두 끝점 사이에 점선을 그립니다. **자유 / 수평 / 수직** 방향과 Shift 방향 제한을 지원합니다. 길이·측정 숫자·눈금은 표시하지 않습니다. 손 탭에서 선택한 점선의 끝점이나 선분을 드래그하거나 방향키로 옮길 수 있으며 이름·계층·삭제·되돌리기도 지원합니다.
- 점선 탭의 **마우스 보정**은 기본 ON입니다. 점·직선·곡선·축·기존 점선과 교점에 붙고 Alt로 잠시 해제합니다. 점 도구의 마우스 조정과 별도 설정이며 사용자가 OFF로 바꾸면 탭을 다시 열어도 유지합니다. Esc나 도구·그래프 전환은 미완성 점선을 취소합니다. 점↔점선 전환은 점 생성 ON/OFF 선택을 유지합니다.
- **복제** 탭에서 그래프·도형 목록·대상 선택으로 원본을 정한 뒤 **복제**를 누릅니다. 직선은 **그대로(×1·평행) / 더 가파르게(×2) / 더 완만하게(×½)** 중 선택합니다. 음수 기울기도 방향을 유지하며 기본은 **세로축 절편 유지**입니다. 예를 들어 `y = −x + 6`은 `y = −2x + 6` 또는 `y = −0.5x + 6`으로 복제합니다. 실행 전 식을 미리 확인할 수 있습니다.
- **복제 옵션**에서 현재 기준점 유지, 가로축/세로축 +1 배치, 하위 항목 포함을 선택합니다. 곡선·점·점선은 형태·좌표 표시 설정을 보존하며 폴더와 하위 계층도 복제합니다. 복제본에는 새 ID와 `D′`, `D′ 2`처럼 구분되는 이름을 붙입니다. 대상은 원본으로 유지하므로 반복 클릭으로 기울기가 의도치 않게 4배·8배가 되지 않습니다. 기본 복제 위치가 같을 때는 **손**으로 새 도형을 선택해 옮깁니다.
- 원본은 그대로 유지되며 복제한 전체 계층은 한 번의 되돌리기로 복원합니다. 수직선은 정확한 수직선을 유지하고, 수평선 기울기는 0입니다. 숫자 범위를 벗어나는 복제는 미리보기에 안내하고 실행을 막습니다.
- **자** 탭은 비활성화했습니다.
- **도형** 목록에서 항목을 다른 항목 위로 드래그하면 그 아래로 들어갑니다. 예를 들어 직선 이름을 ‘수요곡선’으로 바꾼 뒤 곡선을 그 항목 위로 놓을 수 있습니다. 삼각형 버튼으로 접고 펼치며, 폴더 아이콘으로 별도 폴더도 만들 수 있습니다.
- 선택한 항목의 **상위 항목**으로도 분류를 바꿀 수 있습니다. 모바일에서는 이 선택 목록을 사용합니다. **최상위**로 바꾸면 밖으로 꺼냅니다. 상위 항목을 삭제하면 하위 항목은 한 단계 위에 남습니다. 분류 변경과 접기는 그래프의 위치나 표시를 바꾸지 않습니다.
- 손 모드에서 직선·곡선·점·점선 또는 오른쪽 목록을 좌클릭하면 해당 객체를 선택합니다. 빈 평면이나 그래프 제목을 누르면 도형 선택을 해제합니다. 직선·곡선의 흰색 조절점은 해당 도형이 선택된 동안에만 표시합니다.
- 직선을 드래그하면 이동하고, 선택된 직선 양쪽의 흰색 점을 드래그하면 기울기가 바뀝니다.
- 슬라이더는 −90°부터 +90°까지의 방향으로 움직이며, 양 끝에서 정확한 수직선, 가운데에서 수평선이 됩니다. `수직` 버튼으로도 수직선을 만들 수 있습니다. 기울기 숫자 입력에는 범위 제한이 없습니다.
- Tab으로 선을 선택한 뒤 방향키로 이동할 수 있습니다. 기울기 조절 점에서는 방향키로 방향이 0.1°씩 바뀝니다. Shift를 누르면 1 단위로 조절합니다.
- 상단 **JSON** 버튼으로 결과를 확인하고 `econ-studio.json`으로 다운로드합니다. 읽기 전용 출력란에서 직접 복사할 수도 있습니다.
- 상단 배치 버튼 왼쪽 아이콘으로 **되돌리기 / 다시 실행 / 전체 삭제**를 사용할 수 있습니다. 기록이 없으면 해당 버튼이 비활성화됩니다. **Ctrl+Z**로 되돌리고 **Ctrl+Shift+Z / Ctrl+Y**로 다시 실행합니다. 텍스트 입력 중에는 입력란의 기본 되돌리기를 사용합니다.
- 한 번의 드래그·슬라이더 조작·입력란 편집은 한 단계로 되돌립니다. 도형 추가·삭제·이름·형태·좌표·분류·점선 끝점·축 이름·사분면·격자·배치·그래프 이름·축 방향 변경을 복원합니다. 그래프를 선택하는 동작은 편집 기록에 넣지 않습니다. **전체 삭제**는 선택한 그래프의 도형·점·폴더를 지우며 되돌릴 수 있습니다. 축 이름과 영역 설정은 유지합니다. 기록은 최근 100단계이며 새로고침하면 초기화됩니다.

JSON의 `schemaVersion`은 6입니다. `layout.slots`에 그래프 ID와 행·열을, `diagrams`에 숨겨진 그래프까지 모두 기록합니다. 최상위의 기존 도형·좌표계 필드는 `activeDiagramId`에 해당하는 선택한 그래프의 사본입니다. `coordinateSystem`에 선택한 사분면, 원점 배치, 축 이름(`axisNames`)과 축 표시(`axesVisible: true`)를 기록합니다. 축과 이름이 잘리지 않도록 그래프 주변에 여백을 두며, 1사분면의 원점은 그래프 왼쪽 아래, 1·2사분면은 중앙 아래, 전체 사분면은 화면 중앙입니다. 기본은 x가 오른쪽, y가 위쪽으로 증가하며, 반전 시 `xPositive`, `yPositive`와 원점 위치도 함께 기록합니다. 위치는 화면 픽셀이 아닌 내부 좌표로 보관합니다.

모든 `lines`는 ID·이름·색상·기울기(`slope`)·절편(`intercept`)·기준점(`anchor`)과 일반형 계수(`implicit`: `a*x + b*y + c = 0`)를 포함합니다. 수직선은 `vertical: true`, `slope: null`, `intercept: null`, `xIntercept`로 기록합니다. 유한하지만 매우 큰 기울기의 절편이 숫자 표현 범위를 넘으면 `intercept`는 `null`이며 기준점과 일반형 계수로 직선을 표현합니다.

`curves`는 우상향·우하향 방향(`variant`), 기준점(`anchor`), 가운데 구간의 반폭(`span`), 중심 기울기(`slope`), 휘어짐(`bend`)과 내부 좌표의 이차 베지어 제어점(`geometry.controlPoints`)을 포함합니다. 가운데 구간은 `-1 ≤ t ≤ 1`에서 `x = anchor.x + span*t`, `y = anchor.y + span*(slope*t + bend*t²)`로 정의됩니다. 양 끝의 접선 연장 정보는 `geometry.extensions`에 함께 출력합니다. 화면에서는 이 구간과 연장 부분을 선택한 사분면의 작업 영역 경계에서 자릅니다.

`points`는 이름·내부 좌표·좌표 표시 옵션, `dashedLines`는 점선의 시작점(`anchor`)·끝점(`end`), `groups`는 폴더 이름을 포함합니다. 모든 항목의 `parentId`가 계층을 기록하고 `objectOrder`는 종류를 섞은 생성 순서를 기록합니다. 상세 정의는 [JSON 형식](docs/json-format.md)을 참고하십시오.


## GitHub Pages

`node scripts/build.mjs`로 만든 `dist/`는 정적 웹 파일입니다. 앱 경로는 GitHub Pages의 `/econ-app/` 하위 경로를 고려한 상대 경로입니다. 저장소 루트 자체도 정적 사이트로 제공할 수 있습니다. 자동 배포는 설정하지 않았으며 실제 배포 검증은 아직 하지 않았습니다.

작업은 메모리에 보관하므로 새로고침하면 초기화됩니다. JSON으로 결과를 저장할 수 있으며, JSON 불러오기와 자동 저장은 아직 지원하지 않습니다.
