# Econ Studio

경제 그래프를 노트처럼 직접 그려보는 웹 작업 공간입니다. 직선(직선·반직선·선분, 실선·점선), 곡선, 점을 그리고 구역을 칠할 수 있습니다. 좌표축 이름 편집, 마우스 이동·형태 조절, JSON 출력을 지원합니다.

개발을 이어받으실 때는 [작업 인계](HANDOFF.md)를 먼저 읽어 주세요. Claude Code 작업 규칙은 [CLAUDE.md](CLAUDE.md)에 있습니다. 앱 소스·문서·테스트·실행 스크립트는 이 저장소에서 함께 관리합니다. [구조 문서](docs/architecture.md)와 [JSON 형식](docs/json-format.md)에 구현 기준을 정리했습니다.

공통 편집·복제·선택·직렬화는 `GraphObject` 상속 계층을 사용합니다. 곡선 종류의 계산, 자석 포착 정책, SVG 렌더링도 기반 클래스와 하위 클래스에서 공유합니다. [클래스 관계와 확장 방법](docs/architecture.md#공통-클래스와-상속--2026-11-03)에 책임과 등록 절차를 정리했습니다.

드래그·키보드 조작과 손잡이는 전용 모듈로 분리했고, 도구 버튼·숫자/슬라이더는 공통 UI 컴포넌트를 사용합니다. 필수 구현의 누락은 모델 등록 시 검사합니다. [보강한 확장 경계와 검사 구조](docs/architecture.md#확장-경계공통-ui자동-검사-보강--2026-11-04)를 참고하십시오.

곡선 접점은 이동과 점·선분 그리기가 같은 원본 기하를 사용합니다. 대상 제외·기하 캐시·곡선 등록 검사와 도구 간 연속 회귀도 공유합니다. 현재 상태와 제한은 [인계 문서](HANDOFF.md), 신규 기능의 확장 지점은 [구조 문서](docs/architecture.md)에 정리했습니다.

## 로컬 실행

Windows에서는 서버 메뉴를 다음 명령으로 엽니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\server.ps1 -Action menu
```

| 메뉴 | 동작 |
| --- | --- |
| `1` · Start / Open browser | 서버를 백그라운드에서 켜고 브라우저를 엽니다. 이미 켜져 있으면 기존 서버를 사용합니다. |
| `2` · Stop | 이 메뉴나 시작 파일로 실행한 서버를 종료합니다. |
| `3` · Status | 실행 여부와 주소를 확인합니다. |
| `0` · Exit menu | 메뉴만 닫습니다. 서버는 계속 실행됩니다. |

`-Action start`는 서버 시작, `-Action stop`은 종료, `-Action status`는 상태 확인입니다. PATH의 Node.js 20 이상을 먼저 찾고, 없으면 일반 설치 경로(`Program Files\nodejs`, `AppData\Local\Programs\nodejs`)를 확인합니다. 직접 경로를 지정하려면 `ECON_NODE` 환경 변수를 설정합니다.

더블클릭용 `server.cmd`·`start-server.cmd`·`stop-server.cmd`는 컴퓨터마다 따로 만들어 두는 파일이라 저장소에 없고 `.gitignore`에 들어 있습니다. 필요하면 프로젝트 폴더에 다음 내용으로 만듭니다(`-Action`만 `menu`/`start`/`stop`으로 바꿈).

```bat
@echo off
powershell.exe -NoLogo -NoProfile -ExecutionPolicy Bypass -File "%~dp0scripts\server.ps1" -Action menu %*
if errorlevel 1 pause
```

포트를 바꾸거나 터미널에서 상태를 확인할 수도 있습니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\server.ps1 -Action start -Port 5174
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\server.ps1 -Action status
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\server.ps1 -Action stop
```

브라우저를 열지 않고 실행하려면 `-Action start -NoBrowser`를 사용합니다. 사용 중인 포트는 오류로 안내하며 기존 프로그램을 종료하지 않습니다.

서버 기록과 로그는 Git에서 제외된 `.local/server.json`, `.local/server.stdout.log`, `.local/server.stderr.log`에 보관합니다. 아래의 직접 Node 실행 방식으로 켠 서버는 해당 터미널의 Ctrl+C로 종료합니다.

Node.js 20 이상에서 별도의 의존성 설치 없이 실행합니다.

```sh
node scripts/dev-server.mjs
```

데스크톱(2026-11-07부터)과 노트북(2026-11-09부터)에는 Node.js 26.13.0이 PATH에 설치되어 있어 일반 PowerShell·Claude Code에서 `node`를 바로 사용합니다. 새로 설치한 직후에는 터미널을 다시 열어야 인식됩니다. 새 컴퓨터에서는 `winget install OpenJS.NodeJS.LTS`로 설치할 수 있습니다.

데스크톱과 노트북의 작업 폴더를 서로 복사할 필요는 없고 각자 GitHub에서 풀합니다. 서버를 종료할 때는 실행한 PowerShell 창에서 Ctrl+C를 누릅니다. `EADDRINUSE` 오류는 이미 같은 포트의 서버가 실행 중이라는 뜻입니다.

브라우저에서 [앱 열기](http://127.0.0.1:5173/)로 접속합니다.

## 그리기와 편집

- **공통 맞춤 표시:** 점·직선·곡선 그리기와 직선/곡선 이동에서 **대상 선 강조 + 이중 원 + 맞춤 문구**를 같은 방식으로 표시합니다. 모든 자석은 **16px에서 붙고 24px를 넘으면 해제**되며 Alt로 생략합니다. 곡선을 그릴 때도 **접점 맞춤**이 표시되고 Alt/Shift는 포인터가 멈춰 있어도 반영됩니다. [UI 공통 규칙](docs/ui-consistency.md)에 구현·확장 기준을 정리했습니다.

- **칠하기:** 도구막대 **칠하기** → 닫힌 구역에 마우스를 올려 미리보기 → **한 번 클릭**합니다. 칠한 뒤에는 선택 도구로 돌아가고 칠한 구역이 선택됩니다. 구역마다 **다른 색과 A·B·C…**를 자동으로 붙이고 Z 다음은 AA로 이어집니다. 패널에 다음 구역의 색·글자를 표시하며 진하기만 조절하시면 됩니다. 같은 구역 재클릭은 기존 색·글자를 유지하고, 선택 도구로 구역을 클릭하면 색·진하기 변경과 이동·삭제·되돌리기가 가능합니다. 내부의 다른 닫힌 구역은 비워 두며 직선(실선·점선)·곡선·좌표축을 경계로 사용합니다. 격자·화면 테두리는 경계가 아니고 현재 화면 안에서 완전히 닫힌 곳만 칠합니다. 칠한 모양은 경계선과 독립적으로 유지됩니다.

캔버스 위에는 **선택 · 직선 · 곡선 · 점 · 칠하기**를 둡니다. 무엇을 만들거나 복제하면 항상 선택 도구로 돌아가고 결과가 선택됩니다. 점선은 직선 도구에서 고릅니다. 현재 도구만 강조하고 그 아래에 현재 작업을 표시합니다. 오른쪽 위에는 현재 작업 또는 선택한 도형의 설정 하나를, 아래에는 도형 목록을 표시합니다. UI 정리의 근거와 참고 자료는 [사용성 정리](docs/ui-design.md)에 기록했습니다.

- **여러 도형 선택·삭제:** 선택 도구에서 빈 공간을 드래그하면 영역에 닿는 도형을 함께 선택합니다. **Ctrl/Cmd+클릭**으로 추가·해제하고 **Shift+영역 드래그**로 기존 선택에 추가합니다. 도구막대 **삭제 / N개 삭제**, 선택 패널 **선택한 N개 삭제**, **Delete·Backspace**로 지웁니다. 입력란에서는 글자만 편집합니다. 삭제는 한 번에 되돌릴 수 있습니다. 빈 공간 클릭·Esc로 선택을 해제하고 도형 하나를 클릭하면 개별 이동·편집으로 돌아갑니다.
- 그래프 위에서 **마우스 휠**로 좌표평면을 확대·축소합니다(원점 고정, 0.2~10배). 배율은 보기 상태라 되돌리기·JSON에 들어가지 않습니다. 에지워드 상자는 확대하지 않습니다.
- **선택**은 기본 도구입니다. 도형을 클릭해 선택하고 드래그하거나 방향키로 옮깁니다. **Shift+드래그**는 마우스를 더 많이 움직인 방향에 따라 수평·수직으로만 이동합니다. 직선(반직선·선분 포함)·기본/자유 곡선·점 전체와 자유 곡선의 세 점에 적용하며(선분 끝 손잡이는 직선 위로만 움직임) 회전·휘어짐 조절에는 적용하지 않습니다. Shift+방향키는 더 크게 이동합니다. 빈 평면이나 그래프 제목을 누르면 선택을 해제합니다. 생성·복제·합산 중 **Esc** 또는 오른쪽 닫기 버튼으로 선택에 돌아갑니다.
- 선택 도구로 **직선을 이동**하면 같은 그래프의 자유 곡선·기본 곡선에 접하는 위치에서 자석처럼 붙고 **접점**이 표시됩니다. 기울기는 유지하며 16px 이내에서 붙고 24px보다 멀어지면 풀립니다. **Alt**를 누른 채 드래그하면 자유롭게 이동합니다. 놓은 뒤에는 독립된 직선이며 곡선의 이후 변경을 따라가는 연결은 만들지 않습니다.
- 직선의 **x/y절편을 다른 도형의 절편이나 원점에 맞출 때**도 자석 보정을 적용합니다. 기울기·Shift 이동 축을 유지하고 16px 포착/24px 해제·Alt 생략을 사용합니다. 점 찍기는 절편 근처 16px에서 정확한 축 교차 좌표로 붙고 **x절편·y절편·원점**을 표시합니다. 축에서 선을 띄워도 절편은 잡을 수 있습니다.
- **곡선 전체를 이동**해 직선에 접하게 붙이는 것도 가능합니다. 복제한 곡선도 모양을 유지한 채 직선의 현재 기울기에 맞는 접점으로 맞춰집니다. 자유 이동·Shift 수평/수직 이동·Alt 자유 배치와 같은 16px 포착/24px 해제를 사용합니다. 원본·직선은 유지하며 새 연결을 만들지 않습니다. 지나는 접선이 없는 방향에서는 자유 이동을 유지하고 곡선을 임의로 변형하지 않습니다.
- **곡선을 다른 곡선이나 수직합·수평합 가까이 끌면** 서로 접하는 위치에 붙고 **접점 맞춤**과 두 곡선의 강조를 표시합니다. 기본·자유 곡선은 형태를 유지해 평행이동하며, PPC/무차별곡선은 기존 확대·축소나 준선형 축 이동을 유지합니다. 16px 포착/24px 유지·Alt 해제·자유 곡선의 Shift 방향 제한·한 번 되돌리기를 공유합니다. 실제 접점이 없는 단순 교차, 곡선 전체가 일치하는 겹침, 완전보완재의 꺾임에는 이 접점 자석을 적용하지 않습니다. 놓은 뒤 새 따라가기 관계는 생기지 않습니다.
- 곡선끼리 접한 지점에는 **점 생성/이동·선분 생성/끝 손잡이/전체 이동**도 똑같이 붙습니다. 이동 자석과 점/선분이 원본 접점 계산을 공유하며 놓은 뒤에도 **접점 맞춤**과 두 곡선 강조를 유지합니다. Alt·보정 OFF·Shift 제한도 각 도구의 공통 규칙을 따릅니다.
- **찍어 둔 점 근처로 직선·곡선을 이동**하면 그 점을 정확히 지나도록 붙고 **점 맞춤**이 표시됩니다. 직선 기울기와 곡선 모양·점 위치를 유지하며 Shift 방향 제한·Alt 생략·16px 포착/24px 해제를 사용합니다. 더 가까운 명시적 점은 절편·접선 보정에서 이어받을 수 있습니다. 새 따라가기 연결은 만들지 않으며 계산 종속 도형은 대상에서 제외합니다.
- **직선**을 누르고 패널에서 **직선 / 반직선 / 선분**과 **실선 / 점선**을 고른 뒤, 두 곳을 클릭하거나 드래그해 그립니다. 반직선은 첫 점에서 두 번째 점 방향으로 뻗습니다. 두 점은 공통 맞춤(교점·절편·점·접점·최저점·끝점)에 붙고 Alt는 보정 생략입니다. 두 번째 점에서 **Shift**를 누르면 수평·수직 중 마우스 방향에 가까운 쪽으로 잠급니다. 시작점이 곡선 위(PPC·무차별곡선·자유 곡선의 몸체나 두 곡선의 접점)에 있으면 **그 점의 접선**도 후보가 되어, Shift를 누른 채 접선 쪽으로 클릭하면 정확한 접선이 그려집니다(**접선 맞춤**). Alt+Shift는 수평·수직만 잠급니다. 잠긴 방향은 **수평 맞춤 / 수직 맞춤 / 접선 맞춤**으로 표시됩니다.
- **점 맞춤이 먼저입니다.** 찍어 둔 점이 16px 안에 있으면 교점·선·곡선·접점보다 점에 붙습니다. 점·직선·자유 곡선 생성, 점·손잡이 이동, 도형 전체 이동에 모두 같습니다. 그리면 선택 도구로 돌아가고 새 선이 선택됩니다. 고른 종류·모양은 다음에도 유지됩니다. 실선은 그린 순서대로 파랑·빨강·초록·황토·보라·청록을 돌아가며 쓰고, 점선은 항상 회색입니다. 실선↔점선을 바꾸면 색도 그 모양의 기본색으로 바뀝니다. 선택한 직선은 같은 버튼으로 종류·모양을 바꾸고, 기울기를 숫자·슬라이더·프리셋 또는 흰색 손잡이로 바꿉니다. 정확한 수직선도 지원합니다.
- **곡선 → 기본 곡선 → PPC**로 원점 중심의 ¼원호를 추가합니다. 축 위 두 끝점을 끌거나 **가로·세로 반지름**을 각각 바꾸면 타원이 됩니다. 몸체는 비율을 유지해 크기를 바꾸고, 모양 손잡이·**세로 / 가로 비율** 슬라이더는 면적을 유지해 비율을 바꿉니다. 복제·점/접선 맞춤·칠하기·되돌리기를 공유합니다. 중심 이동·회전·합산은 제공하지 않습니다.
- **곡선 → 기본 곡선 → 직각 쌍곡선**으로 `xy = k`의 양수 가지를 추가합니다. 몸체 이동·크기 손잡이·**크기** 슬라이더는 가로·세로 축을 점근선으로 유지하며 크기만 바꿉니다. 복제·점/접선 자석·되돌리기를 공유합니다. 음수 가지·점근선 이동·이 곡선의 합산은 제공하지 않습니다.
- **곡선 → 무차별곡선**에서 콥더글라스·완전대체재·완전보완재·준선형효용을 추가합니다. 함수 입력 없이 흰색 모양 손잡이와 슬라이더로 조절합니다. 완전보완재의 **꺾임 비율** 슬라이더는 꺾임을 왼쪽 아래 원점에서 꺾임을 지나는 직선 위로 옮기며(왼쪽 끝 = 원점, 반대 방향도 같은 원점), 꺾임의 각도는 흰색 손잡이로 바꿉니다. 반대 방향 레온티에프도 꺾임은 왼쪽 아래 원점에서 나가는 직선 위에 있고(팔만 반대), 끌기·맞추기·각도 조절 모두 그 원점 기준입니다. 콥더글라스·완전보완재는 원점 기준 확대·축소, 완전대체재는 기울기를 유지한 평행이동, 준선형은 기본 y축 평행이동이며 **선형 축**에서 x축으로 바꿉니다. 고유 이동은 Shift보다 우선하고 Alt는 자석만 생략합니다. 같은 선호의 다른 수준은 **복제 후 몸체 이동**으로 만듭니다. 직선 맞춤은 매끄러운 접점·완전보완재 꺾임·완전대체재 축 모서리를 사용합니다. 기존 직선·곡선을 복제해 가격효과 도식을 직접 구성할 수 있습니다. 자동 분해·효용함수 입력·무차별곡선 합산은 제공하지 않습니다. [조작과 제한](docs/indifference-design.md)을 참고하십시오.
- 무차별곡선 목록의 **반대 방향**을 켜고 추가하면 네 곡선을 반대 원점 기준으로 뒤집어 그립니다. 선택한 곡선의 **반대 방향** 체크로 방향을 바꿀 수도 있습니다. 에지워드 상자에서는 B 원점 기준이며 총량을 바꾸면 B 원점을 따라 이동합니다. 일반 평면에서는 반대 원점 손잡이를 끌어 곡선 전체를 옮깁니다. 이동·모양 손잡이·직선/곡선 접점·점/선분 맞춤·칠하기는 원래 방향과 같은 계산을 사용합니다.
- **곡선**은 시작점 → 끝점 → 지나는 점을 클릭해 만듭니다. 그래프 안에 **1/3 시작점 · 2/3 끝점 · 3/3 지나는 점**과 좌클릭·Esc 조작이 표시됩니다. 세 번째 점을 직선 위에 찍으면 접점이 연결됩니다. Alt는 자동 연결·스냅을 생략합니다. 가운데 방향은 자동/수평/수직이며, 미완성 곡선은 Esc·도구/그래프/기록 전환에서 취소됩니다.
- 곡선 버튼의 작은 펼침 메뉴를 제거하고, 곡선 그리기 패널의 **기본 곡선**에 방향 그림이 있는 **우하향 + / 우상향 +** 버튼을 뒀습니다. 한 번 눌러 추가하며 다음 곡선 버튼은 그대로 세 점 그리기를 시작합니다. 기본 곡선은 양 끝 접선을 따라 작업 영역 경계까지 이어지고 자유 곡선은 시작점부터 끝점까지만 그립니다. 곡선 그리기 포인터는 점 도구와 같은 원형·좌표 표시를 사용합니다.
- 자유 곡선은 세 점·접선 방향·양쪽 휘어짐 손잡이로 직접 조절합니다. 시작점·끝점은 다른 도구의 **끝점 맞춤** 대상입니다. 오른쪽 **∪·∩·⊂·⊃** 모양 버튼과 **휘어짐 조절**을 제공합니다. 수동 **직선에 접하기** 메뉴는 제거했습니다. 곡선을 그릴 때의 자동 접점 연결과 직선을 이동할 때의 접선 자석 보정은 유지합니다. 연결된 접점은 원본 직선을 따라가며 **연결 해제** 후 자유 편집합니다. 선택한 도형만 편집 손잡이를 표시합니다.
- 자유 곡선의 **최저점 표시**를 켜면 곡선 위에 마커만 표시합니다. 곡선을 편집하면 실제 최저점 위치를 다시 계산하며, 별도 점·직선 생성이나 최저점 따라가기/연결 해제 조작은 없습니다. 최저점은 유한 곡선 전체에서 계산하므로 끝점일 수도 있습니다. 표시 중인 최저점은 점 생성/이동·선분 생성/끝 손잡이/전체 이동·곡선 시작/끝점의 맞춤 대상이며 **최저점 맞춤**으로 표시합니다(16px 포착/24px 유지·Alt 생략 공유). 맞춰도 점의 좌표만 정해지고 관계는 생기지 않습니다. 일반 점의 통과 직선 기능은 유지합니다.
- 선분·반직선을 선택하면 그려진 끝에만 끝 손잡이가 있습니다. 끌면 그 끝이 직선 위에서 움직이며 교점·축(x절편/y절편)·점·접점·다른 선의 끝에 맞춰집니다(16px 포착/24px 유지·Alt 생략). 끌어도 끝이 열리거나 닫히지 않으며, 직선·반직선·선분 전환은 설정 버튼으로만 합니다. 두 선분의 끝을 같은 교점에 맞추면 꺾인 선이 됩니다. 선분·반직선을 통째로 옮기면 그려진 끝이 교점·절편·점·접점·다른 끝·선에 붙습니다(길이·기울기 유지). 직선 설정의 **실선 / 점선**으로 같은 직선의 모양을 바꿉니다. 잘린 끝은 **끝점 맞춤**으로 점·선 그리기의 맞춤 대상이 됩니다. 이동하면 잘린 길이를 유지하고 회전하면 회전 중심에서 끝까지의 거리를 유지합니다. 끝을 자른 직선은 합치기 대상에서 빠집니다.
- 두 곡선이 접한 점에 점을 찍고 **이 점을 지나는 직선**을 누르면 직선이 두 곡선의 공통 접선 기울기로 시작합니다. 접점이 아닌 점·곡선 하나 위의 점·완전보완재 꺾임은 기존 기본 기울기를 씁니다. 기울기 손잡이를 돌리다 공통 접선 근처에 오면 **접선 맞춤**으로 붙습니다(16px 포착/24px 유지·Alt 생략 공유). 회전 맞춤은 회전 중심이 접점일 때만 동작하며, 직선은 점만 따라가고 곡선을 옮겨도 접점을 따라가지 않습니다.
- **점**은 좌클릭으로 만들며, 찍은 뒤 선택 도구로 돌아가고 새 점이 선택됩니다. 마우스 조정은 기본 ON이며 Alt로 잠시 생략합니다. 복제한 직선을 이동해 맞춘 자유 곡선의 접점에도 정확히 붙고 포인터에 **접점**이 표시됩니다. **추가 설정**에서 점 생성 ON/OFF와 새 점의 좌표 표시를 바꿉니다. 기존 점은 선택 후 좌표 표시를 편집합니다. 우클릭은 점을 만들지 않으며 일반 점은 원본 선의 이후 이동을 따라가지 않습니다.
- 캔버스 위 도구막대의 **복제** 버튼에서 원본을 고르고 복제합니다. 직선은 그대로/기울기 ×2/×½를 선택하고 식을 미리 봅니다. 기울기는 현재 기준점을 중심으로 바꾸며 사본은 자동으로 옆에 생성합니다. 반복 복제도 이미 놓인 사본과 같은 자리를 피하고 수평선은 위쪽, 수직선은 옆쪽으로 띄웁니다. 기준점·절편 유지·배치 선택 메뉴는 없으며 하위 항목이 있을 때만 **하위 항목 함께**를 표시합니다. 복제하면 선택 도구로 돌아가고 사본이 선택됩니다. 전체 복제는 한 undo 단계이고 원본을 유지합니다. 복제본은 기존 따라가기 관계를 끊은 독립 사본입니다.
- 위쪽 **합치기**에서 같은 그래프의 직선·기본 곡선을 두 개 이상 선택해 수직합/수평합을 만듭니다. 원본 변경을 자동 반영하고, 기본 음수 기여분 0 처리 또는 부호를 유지한 수학적 합을 고릅니다. 합 추가 후 결과 편집으로 돌아갑니다. 자유 곡선·다른 그래프의 합산, 합 자체의 이동·복제는 지원하지 않습니다.
- **도형** 목록은 종류를 섞은 생성 순서입니다. 항목을 드래그하거나 선택한 도형의 **분류**를 펼쳐 상위 항목을 지정합니다. 폴더 버튼으로 폴더를 만듭니다. 계층은 좌표 이동과 독립적이며, 삭제한 항목의 자식은 상위로 남습니다.
- 원본을 삭제하면 접점·일반 점의 통과 직선은 현재 형태로 남고 연결만 해제합니다. 최저점 표시는 곡선과 함께 사라지며 합산 결과는 원본과 함께 삭제됩니다. 삭제·연결·복제는 모두 되돌릴 수 있습니다.

## 그래프와 저장

- 첫 작업 영역의 **포맷 → 에지워드 상자**에서 가로·세로 총량을 정합니다(기본 10×8). 왼쪽 아래 A 원점과 오른쪽 위 B 원점의 축을 한 상자에 표시하며 네 변에 점·선분을 맞추고 구역을 칠할 수 있습니다. 이후 **그래프 설정**에서 총량·B 축 이름을 바꿉니다. 도형은 A 기준 수학 좌표로 저장되며 화면 크기가 달라져도 상자 비율을 유지합니다. B 방향 무차별곡선은 **반대 방향**으로 추가하고, 그 밖의 곡선은 세 점 자유 곡선으로 직접 그립니다.
- **포맷 → 대면**은 y축 하나를 가운데에 두고 두 그래프를 맞붙인 한 장의 그래프입니다. x축은 양쪽으로 화살표가 있고, 맞은편(왼쪽) 수평축 이름은 **그래프 설정 → 맞은편 수평축**에서 바꿉니다. 한 그래프이므로 직선 하나를 y축 너머까지 그대로 그을 수 있고 자석도 양쪽에서 같이 동작합니다. 무차별곡선·PPC 같은 곡선 종류는 오른쪽에만 그려지므로 맞은편에는 직선·자유 곡선·점·칠하기를 씁니다.
- **포맷 → 상하 2단**은 x 눈금을 맞춘 위·아래 두 그래프를 한 장에 그립니다(예: 위 IS-LM, 아래 AD). 위 그래프 원점은 (0,0), 아래 그래프 원점은 (0, −아래 그래프 높이)이며, 그래프 설정에서 아래 그래프 높이(기본 6)와 아래 축 이름을 바꿉니다. 모든 선은 보이는 그대로 그려집니다. 끝이 없는 직선은 두 그래프를 모두 지나가므로, 한 그래프 안에서 멈추게 하려면 선분으로 그립니다. 보조선은 직선 도구의 **선분·점선**으로 위 교점을 찍고 Shift로 수직을 잠근 채 아래 x축에서 놓으면 됩니다(교점·아래 축 자석). 아래 그래프의 점 좌표는 아래 원점 기준으로 보여 줍니다. 이 포맷은 확대/축소하지 않습니다.
- **포맷 → 상하 3단**은 x 눈금을 맞춘 위·가운데·아래 세 그래프, **포맷 → 2×2**는 위·아래 2단 × 좌우 2단의 네 그래프를 한 장에 그립니다. 그래프마다 원점과 축이 있고(3단: (0,0)·(0,−h)·(0,−2h), 2×2: (0,0)·(w,0)·(0,−h)·(w,−h)), 그래프 설정에서 아래 그래프 높이 h·왼쪽 그래프 너비 w(2×2, 기본 9)·각 그래프의 축 이름을 바꿉니다. 보조선은 선분·점선 + Shift로 긋습니다. 2×2에서는 가로 보조선이 오른쪽 그래프 y축, 세로 보조선이 아래 x축에 붙습니다. 점 좌표는 그 점이 있는 그래프의 원점 기준입니다. 높이·너비를 바꾸면 축만 옮겨지고 이미 그린 도형은 그대로입니다.
- 빈 에지워드 상자에서 **직선**을 누르면 첫 선이 A/B 원점을 잇도록 배치됩니다. 기존 직선도 이동하거나 기울기 손잡이를 양 원점 가까이 끌면 붙습니다. 이미 지나는 원점은 반대 원점으로 회전할 때 유지하며, Alt를 누르면 보정을 생략합니다.
- 상단 **그래프 설정**에서 활성 그래프의 이름·사분면·축 이름·x/y 방향·축 간격을 바꿉니다. 입력은 즉시 반영되고 완료/닫기로 캔버스에 돌아갑니다. 이름을 비우면 해당 축 이름만 숨깁니다. 축 반전은 투영만 바꾸고 내부 좌표·기울기는 유지합니다.
- **축에서 선 띄우기**의 기본 간격은 0.75, 범위는 0.25~2 좌표 단위입니다. 표시·일반 선 위 스냅만 잘라 원본을 유지하고 점은 자르지 않습니다. 선분·반직선도 직선이므로 다른 직선처럼 잘립니다. 절편 스냅은 실제 축 교차 좌표에서 계속 사용할 수 있습니다. **도형 전체 삭제**는 그래프 설정 아래에 있으며 활성 그래프만 비우고 undo할 수 있습니다.
- 처음 열리는 작업 영역에서 포맷(1사분면·1·2사분면·전체 사분면·대면·상하 2단·상하 3단·2×2·에지워드 상자)을 정합니다. 이후 상단 **포맷**으로 바꿉니다. 그래프는 하나입니다(여러 그래프 배치는 2026-11-13에 지웠고 나중에 다시 구현합니다).
- 상단 **되돌리기 / 다시 실행**, **Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y**를 지원합니다. 드래그·슬라이더·텍스트 입력은 한 단계로 묶고 최근 100단계를 보관합니다. 입력란에서는 기본 텍스트 편집 단축키를 유지합니다.
- 상단 **저장**은 JSON 내보내기입니다. 내용을 복사하거나 econ-studio.json을 다운로드합니다. 현재는 메모리 상태여서 새로고침하면 초기화되며 JSON 불러오기·자동 저장은 지원하지 않습니다.

JSON의 `schemaVersion`은 13입니다. `diagrams`에 그래프를 기록합니다(현재 하나). 각 그래프의 `relations`에는 점·선 끝이 어떤 도형 위에 있는지, 어디서 두 도형이 접하는지를 현재 그림에서 계산해 적습니다(자석으로 맞춘 교점·접점이 여기에 드러납니다). 저장 창의 숫자는 소수 6자리로 반올림합니다. `coordinateSystem`에 선택한 사분면, 원점 배치, 축 이름(`axisNames`)과 축 표시(`axesVisible: true`)를 기록합니다. 축과 이름이 잘리지 않도록 그래프 주변에 여백을 두며, 1사분면의 원점은 그래프 왼쪽 아래, 1·2사분면과 대면은 중앙 아래, 전체 사분면은 화면 중앙입니다. 대면 그래프는 `type:'face-to-face'`와 맞은편 그래프 정보(`facing`)를 함께 적습니다. 기본은 x가 오른쪽, y가 위쪽으로 증가하며, 반전 시 `xPositive`, `yPositive`와 원점 위치도 함께 기록합니다. 위치는 화면 픽셀이 아닌 내부 좌표로 보관합니다.

모든 `lines`는 ID·이름·색상·기울기(`slope`)·절편(`intercept`)·기준점(`anchor`)과 일반형 계수(`implicit`: `a*x + b*y + c = 0`)를 포함합니다. 수직선은 `vertical: true`, `slope: null`, `intercept: null`, `xIntercept`로 기록합니다. 유한하지만 매우 큰 기울기의 절편이 숫자 표현 범위를 넘으면 `intercept`는 `null`이며 기준점과 일반형 계수로 직선을 표현합니다.

`curves`에는 무차별곡선도 포함하며 이 객체는 `family`, `anchor`, `shape`, 준선형의 `linearAxis`와 `geometry.type=indifference`를 사용합니다. 반대 방향 곡선은 `orientation:"opposite"`와 `oppositeOrigin`을 추가합니다. 아래 이차식과 접선 연장은 기존 기본 곡선에만 해당합니다.

기본 곡선은 우상향·우하향 방향(`variant`), 기준점(`anchor`), 가운데 구간의 반폭(`span`), 중심 기울기(`slope`), 휘어짐(`bend`)과 내부 좌표의 이차 베지어 제어점(`geometry.controlPoints`)을 포함합니다. 가운데 구간은 `-1 ≤ t ≤ 1`에서 `x = anchor.x + span*t`, `y = anchor.y + span*(slope*t + bend*t²)`로 정의됩니다. 양 끝의 접선 연장 정보는 `geometry.extensions`에 함께 출력합니다. 화면에서는 이 구간과 연장 부분을 선택한 사분면의 작업 영역 경계에서 자릅니다.

`points`는 이름·내부 좌표·좌표 표시 옵션, 점선·선분은 `lines`의 `style`·`extent`(schemaVersion 12에서 별도 `dashedLines` 제거), `groups`는 폴더 이름을 포함합니다. 모든 항목의 `parentId`가 계층을 기록하고 `objectOrder`는 종류를 섞은 생성 순서를 기록합니다. 상세 정의는 [JSON 형식](docs/json-format.md)을 참고하십시오.

```sh
node scripts/check.mjs
node scripts/test.mjs
node scripts/build.mjs
node scripts/browser-test.mjs
```

## GitHub Pages

`node scripts/build.mjs`로 만든 `dist/`는 정적 웹 파일입니다. 앱 경로는 GitHub Pages의 `/econ-app/` 하위 경로를 고려한 상대 경로입니다. 저장소 루트 자체도 정적 사이트로 제공할 수 있습니다. 프로젝트의 `Check` 워크플로에는 배포 단계가 없습니다. 다만 기존 저장소의 별도 Pages 설정으로 `main` 푸시 시 GitHub 관리형 `pages build and deployment`가 자동 실행되는 것을 2026-11-04에 확인했습니다. 이번 작업에서 배포 명령이나 Pages 설정 변경은 하지 않았으며, 배포 실행 상태와 실제 사이트 검증은 로컬 빌드/CI와 구분합니다.

작업은 메모리에 보관하므로 새로고침하면 초기화됩니다. JSON으로 결과를 저장할 수 있으며, JSON 불러오기와 자동 저장은 아직 지원하지 않습니다.
