# Econ Studio

경제 그래프를 직접 그려보는 웹 작업 공간입니다. 직선, 우상향·우하향 곡선, 이름 있는 점과 보조선을 그리고 도형을 폴더처럼 정리할 수 있습니다. 좌표축 이름 편집, 마우스 이동·형태 조절, JSON 출력을 지원합니다.

개발을 이어받으실 때는 [작업 인계](HANDOFF.md)를 먼저 읽어 주세요. 앱 소스·문서·테스트·실행 스크립트는 이 저장소에서 함께 관리합니다. [구조 문서](docs/architecture.md)와 [JSON 형식](docs/json-format.md)에 구현 기준을 정리했습니다.

## 로컬 실행

Windows에서는 프로젝트 폴더의 **`server.cmd`를 더블클릭**하면 서버 메뉴가 열립니다.

| 메뉴 | 동작 |
| --- | --- |
| `1` · Start / Open browser | 서버를 백그라운드에서 켜고 브라우저를 엽니다. 이미 켜져 있으면 기존 서버를 사용합니다. |
| `2` · Stop | 이 메뉴나 시작 파일로 실행한 서버를 종료합니다. |
| `3` · Status | 실행 여부와 주소를 확인합니다. |
| `0` · Exit menu | 메뉴만 닫습니다. 서버는 계속 실행됩니다. |

**`start-server.cmd`**는 서버 시작, **`stop-server.cmd`**는 서버 종료를 바로 실행합니다. 파일은 다른 작업 폴더에서 실행해도 동작합니다. PATH의 Node.js 20 이상을 먼저 찾고, 없으면 현재 컴퓨터의 Codex 번들 Node 경로를 자동 확인합니다. 직접 경로를 지정하려면 `ECON_NODE` 환경 변수를 설정합니다.

포트를 바꾸거나 터미널에서 상태를 확인할 수도 있습니다.

```powershell
.\start-server.cmd -Port 5174
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\server.ps1 -Action status
.\stop-server.cmd
```

브라우저를 열지 않고 실행하려면 `start-server.cmd -NoBrowser`를 사용합니다. 사용 중인 포트는 오류로 안내하며 기존 프로그램을 종료하지 않습니다. 서버 기록과 로그는 Git에서 제외된 `.local/server.json`, `.local/server.stdout.log`, `.local/server.stderr.log`에 보관합니다. 아래의 직접 Node 실행 방식으로 켠 서버는 해당 터미널의 Ctrl+C로 종료합니다.

Node.js 20 이상에서 별도의 의존성 설치 없이 실행합니다.

```sh
node scripts/dev-server.mjs
```

현재 컴퓨터의 일반 PowerShell에서 `node`를 찾지 못하면, Codex에 포함된 실행 파일을 직접 사용합니다. 아래 경로의 Node.js 24.19.0 실행을 확인했습니다.

```powershell
cd "C:\Users\htt06\OneDrive\바탕 화면\econ-app"
& "C:\Users\htt06\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin\node.exe" scripts/dev-server.mjs
```

이 경로는 현재 컴퓨터의 Codex 런타임 경로입니다. 다른 환경에서는 Node.js 20 이상을 준비한 뒤 `node` 명령을 사용합니다. 서버를 종료할 때는 실행한 PowerShell 창에서 Ctrl+C를 누릅니다. `EADDRINUSE` 오류는 이미 같은 포트의 서버가 실행 중이라는 뜻입니다.

브라우저에서 http://127.0.0.1:5173 에 접속합니다.

- **직선 +** 버튼을 누를 때마다 새 직선을 추가합니다.
- **곡선 +** 버튼은 우하향·우상향 곡선을 번갈아 추가합니다. 선택 후 **우상향 / 우하향** 버튼으로 방향을 바꿀 수 있습니다. 이름은 방향 변경과 별도로 유지됩니다.
- 곡선은 드래그로 이동하고, **휘어짐** 슬라이더 또는 곡선 위 흰색 점의 위아래 드래그로 곡률을 조절합니다. 0%는 직선 형태이며, 최대 휘어짐에서도 각 방향을 유지합니다.
- 곡선 양 끝은 끝점의 기울기를 따라 축이나 작업 영역 경계까지 이어 표시합니다. 추가하거나 이동했을 때 화면 중간에서 짧게 끊기지 않으며, 이어진 부분도 드래그할 수 있습니다.
- 오른쪽 **축** 영역에서 수평축·수직축의 이름을 입력합니다. 입력 즉시 화면과 JSON에 반영됩니다. 이름을 비우면 해당 축의 이름만 숨깁니다.
- 처음 열리는 **작업 영역** 창에서 1사분면, 1·2사분면, 전체 사분면을 선택합니다. 상단 버튼으로 나중에 바꿀 수 있습니다. 영역 변경은 기존 도형의 내부 좌표를 유지하며, 영역 밖의 부분만 화면에서 숨깁니다.
- **마우스**를 선택하면 그래프 포인터가 바로 점선 원으로 바뀌고 현재 `(x, y)`가 계속 따라다닙니다. **점 생성**을 켜면 그래프 우클릭으로 점을 만듭니다. 좌클릭 선택·드래그는 유지됩니다. 마우스를 다시 누르거나 직선·곡선을 추가하면 선택을 해제하며, 마우스를 다시 선택하면 이전 옵션을 사용합니다. 점 생성 토글을 끄거나 Esc를 누르면 생성을 종료합니다.
- **마우스 조정**은 가까운 직선·곡선·축·다른 점의 보조선에 붙는 기능을 켜고 끕니다. 교점은 더 넓은 범위에서 우선 잡히며 ‘교점’과 정확한 좌표를 표시합니다. 우클릭 생성·점 드래그에도 같은 보정을 적용합니다. 떨어진 곳에서는 자유롭게 움직이고 Alt를 누르면 일시적으로 보정을 생략합니다. 조정을 꺼도 마우스가 선택되어 있으면 원과 좌표는 유지됩니다. 그래프를 벗어나면 표시를 숨깁니다. 방향키 이동은 보정하지 않습니다. 선을 나중에 움직여도 점은 기존 좌표에 남습니다.
- **좌표 함께 표시**를 켜면 새 점에 `(x, y)` 좌표를 함께 표시합니다. 표시값은 소수 둘째 자리까지 반올림하며 점 이동에 따라 갱신됩니다. 기존 점은 점 설정의 **좌표 표시**로 따로 켜고 끕니다. 내부 좌표와 JSON은 원래 정밀도를 유지합니다.
- 선택한 항목의 **이름**을 입력하면 목록에 반영됩니다. 점의 이름은 그래프에도 표시됩니다. 점의 **보조선**에서 수평·수직을 각각 없음/점선/실선으로 정하고, 범위는 **축까지 / 영역 전체**로 선택합니다. 보조선은 점을 따라 이동합니다.
- **도형** 목록에서 항목을 다른 항목 위로 드래그하면 그 아래로 들어갑니다. 예를 들어 직선 이름을 ‘수요곡선’으로 바꾼 뒤 곡선을 그 항목 위로 놓을 수 있습니다. 삼각형 버튼으로 접고 펼치며, 폴더 아이콘으로 별도 폴더도 만들 수 있습니다.
- 선택한 항목의 **상위 항목**으로도 분류를 바꿀 수 있습니다. 모바일에서는 이 선택 목록을 사용합니다. **최상위**로 바꾸면 밖으로 꺼냅니다. 상위 항목을 삭제하면 하위 항목은 한 단계 위에 남습니다. 분류 변경과 접기는 그래프의 위치나 표시를 바꾸지 않습니다.
- 직선·곡선·점 또는 오른쪽 목록을 좌클릭하면 해당 객체를 선택합니다. 빈 평면을 좌클릭하면 선택을 해제합니다.
- 직선을 드래그하면 이동하고, 선택된 직선 양쪽의 흰색 점을 드래그하면 기울기가 바뀝니다.
- 슬라이더는 −90°부터 +90°까지의 방향으로 움직이며, 양 끝에서 정확한 수직선, 가운데에서 수평선이 됩니다. `수직` 버튼으로도 수직선을 만들 수 있습니다. 기울기 숫자 입력에는 범위 제한이 없습니다.
- Tab으로 선을 선택한 뒤 방향키로 이동할 수 있습니다. 기울기 조절 점에서는 방향키로 방향이 0.1°씩 바뀝니다. Shift를 누르면 1 단위로 조절합니다.
- 상단 **JSON** 버튼으로 결과를 확인하고 `econ-studio.json`으로 다운로드합니다. 읽기 전용 출력란에서 직접 복사할 수도 있습니다.
- 상단 사분면 버튼 왼쪽 아이콘으로 **되돌리기 / 다시 실행 / 전체 삭제**를 사용할 수 있습니다. 기록이 없으면 해당 버튼이 비활성화됩니다. **Ctrl+Z**로 되돌리고 **Ctrl+Shift+Z / Ctrl+Y**로 다시 실행합니다. 텍스트 입력 중에는 입력란의 기본 되돌리기를 사용합니다.
- 한 번의 드래그·슬라이더 조작·입력란 편집은 한 단계로 되돌립니다. 도형 추가·삭제·이름·형태·좌표·분류·보조선·축 이름·사분면·격자 변경을 복원합니다. **전체 삭제**는 도형·점·폴더를 지우며 되돌릴 수 있습니다. 축 이름과 영역 설정은 유지합니다. 기록은 최근 100단계이며 새로고침하면 초기화됩니다.

JSON의 `schemaVersion`은 3입니다. `coordinateSystem`에 선택한 사분면, 원점 배치, 축 이름(`axisNames`)과 축 표시(`axesVisible: true`)를 기록합니다. 축과 이름이 잘리지 않도록 그래프 주변에 여백을 두며, 1사분면의 원점은 그래프 왼쪽 아래, 1·2사분면은 중앙 아래, 전체 사분면은 화면 중앙입니다. x는 오른쪽, y는 위쪽으로 증가합니다. 위치는 화면 픽셀이 아닌 내부 좌표로 보관합니다.

모든 `lines`는 ID·이름·색상·기울기(`slope`)·절편(`intercept`)·기준점(`anchor`)과 일반형 계수(`implicit`: `a*x + b*y + c = 0`)를 포함합니다. 수직선은 `vertical: true`, `slope: null`, `intercept: null`, `xIntercept`로 기록합니다. 유한하지만 매우 큰 기울기의 절편이 숫자 표현 범위를 넘으면 `intercept`는 `null`이며 기준점과 일반형 계수로 직선을 표현합니다.

`curves`는 우상향·우하향 방향(`variant`), 기준점(`anchor`), 가운데 구간의 반폭(`span`), 중심 기울기(`slope`), 휘어짐(`bend`)과 내부 좌표의 이차 베지어 제어점(`geometry.controlPoints`)을 포함합니다. 가운데 구간은 `-1 ≤ t ≤ 1`에서 `x = anchor.x + span*t`, `y = anchor.y + span*(slope*t + bend*t²)`로 정의됩니다. 양 끝의 접선 연장 정보는 `geometry.extensions`에 함께 출력합니다. 화면에서는 이 구간과 연장 부분을 선택한 사분면의 작업 영역 경계에서 자릅니다.

`points`는 이름·내부 좌표와 `guides` 설정, `groups`는 폴더 이름을 포함합니다. 모든 항목의 `parentId`가 계층을 기록하고 `objectOrder`는 종류를 섞은 생성 순서를 기록합니다. 상세 정의는 [JSON 형식](docs/json-format.md)을 참고하십시오.

```sh
node --test
node scripts/build.mjs
```

일반적인 npm 환경에서는 `npm run dev`, `npm test`, `npm run build`도 사용할 수 있습니다.

## 구조

- `src/main.js`: 앱 화면 구성과 연결
- `src/state.js`: 도구와 그래프가 공유하는 상태
- `src/tools/line.js`: 직선 도구와 기울기 입력
- `src/tools/curve.js`: 우상향·우하향 곡선과 휘어짐 입력
- `src/tools/objects.js`: 도형·폴더 계층 목록과 이름·분류·삭제 설정
- `src/tools/point.js`: 마우스 선택·우클릭 점 생성·좌표·보조선 설정
- `src/history.js`: 되돌리기·다시 실행·전체 삭제·단축키·편집 묶음
- `src/objects.js`: 도형 생성 순서와 계층 순환 검사
- `src/graph/point.js`: 점의 보조선 계산
- `src/graph/snap.js`: 선·곡선의 최근접점과 교점 보정
- `src/graph/math.js`: 화면과 독립적인 그래프 계산
- `src/graph/curve.js`: 곡선의 내부 좌표와 베지어 제어점 계산
- `src/graph/canvas.js`: 반응형 SVG 좌표평면
- `src/graph/viewport.js`: 사분면과 내부 좌표 범위
- `src/quadrants.js`: 시작 시 작업 영역 선택 창
- `src/axes.js`: 수평축·수직축 이름 입력
- `src/export.js`: JSON 스키마와 미리보기·다운로드
- `src/styles.css`: 데스크톱과 모바일 화면
- `server.cmd`, `start-server.cmd`, `stop-server.cmd`: Windows 서버 메뉴·시작·종료 실행 파일
- `scripts/server.ps1`: Node 탐색, 백그라운드 서버 시작·종료·상태 확인

## GitHub Pages

`node scripts/build.mjs`로 만든 `dist/`는 정적 웹 파일입니다. 앱 경로는 GitHub Pages의 `/econ-app/` 하위 경로를 고려한 상대 경로입니다. 저장소 루트 자체도 정적 사이트로 제공할 수 있습니다. 자동 배포는 설정하지 않았으며 실제 배포 검증은 아직 하지 않았습니다.

작업은 메모리에 보관하므로 새로고침하면 초기화됩니다. JSON으로 결과를 저장할 수 있으며, JSON 불러오기와 자동 저장은 아직 지원하지 않습니다.
