# Econ Studio

여러 경제 그래프를 배치하고 직접 그려보는 웹 작업 공간입니다. 직선, 우상향·우하향 곡선, 이름 있는 점과 점선을 그리고 도형을 폴더처럼 정리할 수 있습니다. 좌표축 이름 편집, 마우스 이동·형태 조절, JSON 출력을 지원합니다.

개발을 이어받으실 때는 [작업 인계](HANDOFF.md)를 먼저 읽어 주세요. 앱 소스·문서·테스트·실행 스크립트는 이 저장소에서 함께 관리합니다. [구조 문서](docs/architecture.md)와 [JSON 형식](docs/json-format.md)에 구현 기준을 정리했습니다.

## 로컬 실행

Windows에서는 프로젝트 폴더의 **`server.cmd`를 더블클릭**하면 서버 메뉴가 열립니다.

| 메뉴 | 동작 |
| --- | --- |
| `1` · Start / Open browser | 서버를 백그라운드에서 켜고 브라우저를 엽니다. 이미 켜져 있으면 기존 서버를 사용합니다. |
| `2` · Stop | 이 메뉴나 시작 파일로 실행한 서버를 종료합니다. |
| `3` · Status | 실행 여부와 주소를 확인합니다. |
| `0` · Exit menu | 메뉴만 닫습니다. 서버는 계속 실행됩니다. |

**`start-server.cmd`**는 서버 시작, **`stop-server.cmd`**는 서버 종료를 바로 실행합니다. 파일은 다른 작업 폴더에서 실행해도 동작합니다. PATH의 Node.js 20 이상을 먼저 찾고, 없으면 현재 컴퓨터의 Codex 번들 Node 경로를 자동 확인합니다. 직접 경로를 지정하려면 `ECON_NODE` 환경 변수를 설정합니다.

포트를 바꾸거나 터미널에서 상태를 확인할 수도 있습니다.

```powershell
.\start-server.cmd -Port 5174
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\server.ps1 -Action status
.\stop-server.cmd
```

브라우저를 열지 않고 실행하려면 `start-server.cmd -NoBrowser`를 사용합니다. 사용 중인 포트는 오류로 안내하며 기존 프로그램을 종료하지 않습니다. 다른 데스크톱의 세 .cmd 실행 파일에 기기 전용 수정본과 skip-worktree 설정이 있는 경우 이를 유지하고 GitHub에 올리지 않습니다. 현재 실행 파일은 저장소에서 삭제하지 않습니다.

서버 기록과 로그는 Git에서 제외된 `.local/server.json`, `.local/server.stdout.log`, `.local/server.stderr.log`에 보관합니다. 아래의 직접 Node 실행 방식으로 켠 서버는 해당 터미널의 Ctrl+C로 종료합니다.

Node.js 20 이상에서 별도의 의존성 설치 없이 실행합니다.

```sh
node scripts/dev-server.mjs
```

현재 컴퓨터의 일반 PowerShell에서 `node`를 찾지 못하면, Codex에 포함된 실행 파일을 직접 사용합니다. 아래 경로의 Node.js 24.22.1 실행을 확인했습니다.

```powershell
cd "C:\Users\htt06\OneDrive\바탕 화면\econ-app"
& "C:\Users\htt06\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin\node.exe" scripts/dev-server.mjs
```

이 경로는 현재 컴퓨터의 Codex 런타임 경로입니다. 다른 환경에서는 Node.js 20 이상을 준비한 뒤 `node` 명령을 사용합니다. 서버를 종료할 때는 실행한 PowerShell 창에서 Ctrl+C를 누릅니다. `EADDRINUSE` 오류는 이미 같은 포트의 서버가 실행 중이라는 뜻입니다.

브라우저에서 [앱 열기](http://127.0.0.1:5173/)로 접속합니다.

## 그리기와 편집

캔버스 위에는 **선택 · 직선 · 곡선 · 점 · 점선**을 둡니다. 현재 도구만 강조하고 그 아래에 현재 작업을 표시합니다. 오른쪽 위에는 현재 작업 또는 선택한 도형의 설정 하나를, 아래에는 도형 목록을 표시합니다. UI 정리의 근거와 참고 자료는 [사용성 정리](docs/ui-design.md)에 기록했습니다.

- **선택**은 기본 도구입니다. 도형을 클릭해 선택하고 드래그하거나 방향키로 옮깁니다. Shift+방향키는 더 크게 이동합니다. 빈 평면이나 그래프 제목을 누르면 선택을 해제합니다. 생성·복제·합산 중 **Esc** 또는 오른쪽 닫기 버튼으로 선택에 돌아갑니다.
- **직선**은 클릭할 때마다 추가합니다. 선택한 직선의 기울기를 숫자·슬라이더·프리셋 또는 흰색 손잡이로 바꿉니다. 정확한 수직선도 지원합니다.
- **곡선**은 시작점 → 끝점 → 지나는 점을 클릭해 만듭니다. 세 번째 점을 직선 위에 찍으면 접점이 연결됩니다. Alt는 자동 연결·스냅을 생략합니다. 가운데 방향은 자동/수평/수직이며, 미완성 곡선은 Esc·도구/그래프/기록 전환에서 취소됩니다.
- 곡선 옆 **⌄** 메뉴에는 **우하향 곡선 추가 / 우상향 곡선 추가**가 있습니다. 기본 곡선은 양 끝 접선을 따라 작업 영역 경계까지 이어집니다. 기존 자유 곡선은 시작점부터 끝점까지만 그립니다.
- 자유 곡선은 세 점·접선 방향·양쪽 휘어짐 손잡이로 직접 조절합니다. 오른쪽 **∪·∩·⊂·⊃** 모양 버튼, **휘어짐 조절**, **직선에 접하기**도 제공합니다. 연결된 접점은 원본 직선을 따라가며 **연결 해제** 후 자유 편집합니다. 선택한 도형만 편집 손잡이를 표시합니다.
- 자유 곡선의 **최저점 표시** → 생성된 점의 **이 점을 지나는 직선**으로 최저점을 지나는 선을 만듭니다. 곡선을 바꾸면 점과 선이 따라갑니다. 최저점은 유한 곡선 전체에서 계산하므로 끝점일 수도 있습니다. 일반 점에도 통과 직선을 만들 수 있습니다.
- **점**은 좌클릭으로 만듭니다. 마우스 조정은 기본 ON이며 Alt로 잠시 생략합니다. **추가 설정**에서 점 생성 ON/OFF와 새 점의 좌표 표시를 바꿉니다. 기존 점은 선택 후 좌표 표시를 편집합니다. 우클릭은 점을 만들지 않으며 일반 점은 원본 선의 이후 이동을 따라가지 않습니다.
- **점선**은 두 위치를 클릭하거나 드래그해 만듭니다. 자유/수평/수직 방향, Shift 방향 제한과 별도의 기본 ON 마우스 보정을 지원합니다. 선택 도구에서 끝점·전체 선분을 편집합니다. 길이·측정 눈금은 표시하지 않으며 자 도구는 기본 화면에서 제공하지 않습니다.
- 오른쪽 **복제**는 선택한 도형에 적용합니다. 직선은 그대로/기울기 ×2/×½를 선택하고 식을 미리 봅니다. 기본은 세로축 절편 유지이며 **복제 옵션**에서 기준점·배치·하위 항목 포함을 바꿉니다. 전체 복제는 한 undo 단계이고 원본을 유지합니다. 자유 곡선·점·직선의 복제본은 기존 따라가기 관계를 끊은 독립 사본입니다.
- 위쪽 **합치기**에서 같은 그래프의 직선·기본 곡선을 두 개 이상 선택해 수직합/수평합을 만듭니다. 원본 변경을 자동 반영하고, 기본 음수 기여분 0 처리 또는 부호를 유지한 수학적 합을 고릅니다. 합 추가 후 결과 편집으로 돌아갑니다. 자유 곡선·다른 그래프의 합산, 합 자체의 이동·복제는 지원하지 않습니다.
- **도형** 목록은 종류를 섞은 생성 순서입니다. 항목을 드래그하거나 선택한 도형의 **분류**를 펼쳐 상위 항목을 지정합니다. 폴더 버튼으로 폴더를 만듭니다. 계층은 좌표 이동과 독립적이며, 삭제한 항목의 자식은 상위로 남습니다.
- 원본을 삭제하면 접점·최저점·통과 직선의 종속 도형은 현재 형태로 남고 연결만 해제합니다. 합산 결과는 원본과 함께 삭제됩니다. 삭제·연결·복제는 모두 되돌릴 수 있습니다.

## 그래프와 저장

- 상단 **그래프 설정**에서 활성 그래프의 이름·사분면·축 이름·x/y 방향·축 간격을 바꿉니다. 입력은 즉시 반영되고 완료/닫기로 캔버스에 돌아갑니다. 이름을 비우면 해당 축 이름만 숨깁니다. 축 반전은 투영만 바꾸고 내부 좌표·기울기는 유지합니다.
- **축에서 선 띄우기**의 기본 간격은 0.75, 범위는 0.25~2 좌표 단위입니다. 표시·스냅만 잘라 원본을 유지하고 점·점선은 자르지 않습니다. **도형 전체 삭제**는 그래프 설정 아래에 있으며 활성 그래프만 비우고 undo할 수 있습니다.
- 처음 열리는 작업 영역에서 배치·사분면을 정합니다. 이후 상단 **배치 · N개**로 바꿉니다. 가로/세로 2·3개, ㄴ자, 좌우/상하 대면, 격자와 최대 3×3 직접 배치를 지원합니다. 배치를 줄여도 숨긴 그래프를 보관합니다.
- 그래프 제목·평면을 눌러 편집할 그래프를 선택합니다. 도형·축·격자·삭제는 활성 그래프에 적용합니다. 다른 그래프로 전환하면 복제·합산 작업은 닫힙니다. 좁은 화면에서도 그래프 배치의 행·열 위치를 유지하고 그래프 영역 안에서 스크롤합니다.
- 상단 **되돌리기 / 다시 실행**, **Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y**를 지원합니다. 드래그·슬라이더·텍스트 입력은 한 단계로 묶고 최근 100단계를 보관합니다. 입력란에서는 기본 텍스트 편집 단축키를 유지합니다.
- 상단 **저장**은 JSON 내보내기입니다. 내용을 복사하거나 econ-studio.json을 다운로드합니다. 현재는 메모리 상태여서 새로고침하면 초기화되며 JSON 불러오기·자동 저장은 지원하지 않습니다.

JSON의 `schemaVersion`은 8입니다. `layout.slots`에 그래프 ID와 행·열을, `diagrams`에 숨겨진 그래프까지 모두 기록합니다. 최상위의 기존 도형·좌표계 필드는 `activeDiagramId`에 해당하는 선택한 그래프의 사본입니다. `coordinateSystem`에 선택한 사분면, 원점 배치, 축 이름(`axisNames`)과 축 표시(`axesVisible: true`)를 기록합니다. 축과 이름이 잘리지 않도록 그래프 주변에 여백을 두며, 1사분면의 원점은 그래프 왼쪽 아래, 1·2사분면은 중앙 아래, 전체 사분면은 화면 중앙입니다. 기본은 x가 오른쪽, y가 위쪽으로 증가하며, 반전 시 `xPositive`, `yPositive`와 원점 위치도 함께 기록합니다. 위치는 화면 픽셀이 아닌 내부 좌표로 보관합니다.

모든 `lines`는 ID·이름·색상·기울기(`slope`)·절편(`intercept`)·기준점(`anchor`)과 일반형 계수(`implicit`: `a*x + b*y + c = 0`)를 포함합니다. 수직선은 `vertical: true`, `slope: null`, `intercept: null`, `xIntercept`로 기록합니다. 유한하지만 매우 큰 기울기의 절편이 숫자 표현 범위를 넘으면 `intercept`는 `null`이며 기준점과 일반형 계수로 직선을 표현합니다.

`curves`는 우상향·우하향 방향(`variant`), 기준점(`anchor`), 가운데 구간의 반폭(`span`), 중심 기울기(`slope`), 휘어짐(`bend`)과 내부 좌표의 이차 베지어 제어점(`geometry.controlPoints`)을 포함합니다. 가운데 구간은 `-1 ≤ t ≤ 1`에서 `x = anchor.x + span*t`, `y = anchor.y + span*(slope*t + bend*t²)`로 정의됩니다. 양 끝의 접선 연장 정보는 `geometry.extensions`에 함께 출력합니다. 화면에서는 이 구간과 연장 부분을 선택한 사분면의 작업 영역 경계에서 자릅니다.

`points`는 이름·내부 좌표·좌표 표시 옵션, `dashedLines`는 점선의 시작점(`anchor`)·끝점(`end`), `groups`는 폴더 이름을 포함합니다. 모든 항목의 `parentId`가 계층을 기록하고 `objectOrder`는 종류를 섞은 생성 순서를 기록합니다. 상세 정의는 [JSON 형식](docs/json-format.md)을 참고하십시오.

```sh
node --test
node scripts/build.mjs
```

2026-10-28 검증: UI 상태 회귀 4개, 자유 곡선·관계 회귀 15개, 합산 11개와 Windows 서버 3개를 포함해 전체 테스트 117개, 정적 빌드가 통과했습니다. Windows 서버 테스트는 다른 운영체제에서 건너뜁니다. 실제 브라우저 검증 범위와 미검증 제한은 HANDOFF에 별도로 기록했습니다. 최신 목표는 자유로운 도식 그리기이며, 함수 기반 경제 모형 계산은 구현하지 않았습니다. [설계 검토](docs/tangency-design.md)는 초기 제안과 최신 판단을 구분합니다.

일반적인 npm 환경에서는 `npm run dev`, `npm test`, `npm run build`도 사용할 수 있습니다.

## 구조

- `src/main.js`: 도구막대·편집 패널·설정 창 마크업과 기능 연결
- `src/editor-ui.js`, `src/editor.css`: 현재 작업에 맞는 편집 패널과 반응형 레이아웃
- `src/duplicate.js`: 복제용 기하·기울기·절편 보존과 검증
- `src/graph/sum.js`, `src/tools/sum.js`: 원본에 연동되는 수직합·수평합 계산·표시·선택 UI
- `src/graph/sketch.js`, `src/graph/sketch-view.js`, `src/tools/sketch.js`: 세 점 자유 곡선·손잡이·모양·접점·최저점 UI
- `src/relations.js`: 직선과의 접점·최저점·통과 직선의 따라가기와 순환 방지
- `src/tools/hand.js`: 손 선택 모드와 Esc
- `src/tools/duplicate.js`: 복제 대상·기울기·기준·배치·하위 항목 UI
- `src/state.js`: 도구와 그래프가 공유하는 상태
- `src/tools/line.js`: 직선 도구와 기울기 입력
- `src/tools/curve.js`: 우상향·우하향 곡선과 휘어짐 입력
- `src/tools/objects.js`: 도형·폴더 계층 목록과 이름·분류·삭제 설정
- `src/graph/ruler.js`: 공유 유한 선분의 클리핑·방향 제한·이동 계산과 보관 중인 자 계산
- `src/graph/dashed-view.js`: 점선과 선택한 두 끝점의 SVG 렌더

- `src/tools/point.js`: 점 도구 선택·좌클릭 점 생성·좌표 설정
- `src/history.js`: 되돌리기·다시 실행·전체 삭제·단축키·편집 묶음
- `src/objects.js`: 도형 생성 순서와 계층 순환 검사
- `src/graph/point.js`: 점 좌표 표시용 반올림
- `src/graph/snap.js`: 선·곡선의 최근접점과 교점 보정
- `src/graph/math.js`: 화면과 독립적인 그래프 계산
- `src/graph/curve.js`: 곡선의 내부 좌표와 베지어 제어점 계산
- `src/graph/canvas.js`: 반응형 SVG 좌표평면

## GitHub Pages

`node scripts/build.mjs`로 만든 `dist/`는 정적 웹 파일입니다. 앱 경로는 GitHub Pages의 `/econ-app/` 하위 경로를 고려한 상대 경로입니다. 저장소 루트 자체도 정적 사이트로 제공할 수 있습니다. 자동 배포는 설정하지 않았으며 실제 배포 검증은 아직 하지 않았습니다.

작업은 메모리에 보관하므로 새로고침하면 초기화됩니다. JSON으로 결과를 저장할 수 있으며, JSON 불러오기와 자동 저장은 아직 지원하지 않습니다.
