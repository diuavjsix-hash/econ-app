# Econ Studio

여러 경제 그래프를 배치하고 직접 그려보는 웹 작업 공간입니다. 직선, 곡선, 점과 점선을 그리고 구역을 칠할 수 있습니다. 좌표축 이름 편집, 마우스 이동·형태 조절, JSON 출력을 지원합니다.

개발을 이어받으실 때는 [작업 인계](HANDOFF.md)를 먼저 읽어 주세요. 앱 소스·문서·테스트·실행 스크립트는 이 저장소에서 함께 관리합니다. [구조 문서](docs/architecture.md)와 [JSON 형식](docs/json-format.md)에 구현 기준을 정리했습니다.

공통 편집·복제·선택·직렬화는 `GraphObject` 상속 계층을 사용합니다. 곡선 종류의 계산, 자석 포착 정책, SVG 렌더링도 기반 클래스와 하위 클래스에서 공유합니다. [클래스 관계와 확장 방법](docs/architecture.md#공통-클래스와-상속--2026-11-03)에 책임과 등록 절차를 정리했습니다.

드래그·키보드 조작과 손잡이는 전용 모듈로 분리했고, 도구 버튼·숫자/슬라이더는 공통 UI 컴포넌트를 사용합니다. 필수 구현의 누락은 모델 등록 시 검사합니다. [보강한 확장 경계와 검사 구조](docs/architecture.md#확장-경계공통-ui자동-검사-보강--2026-11-04)를 참고하십시오.

곡선 접점은 이동과 점·점선이 같은 원본 기하를 사용합니다. 대상 제외·기하 캐시·곡선 등록 검사와 도구 간 연속 회귀도 공유합니다. 현재 상태와 제한은 [인계 문서](HANDOFF.md), 신규 기능의 확장 지점은 [구조 문서](docs/architecture.md)에 정리했습니다.

## 로컬 실행

Windows에서는 프로젝트 폴더의 **`server.cmd`를 더블클릭**하면 서버 메뉴가 열립니다.

| 메뉴 | 동작 |
| --- | --- |
| `1` · Start / Open browser | 서버를 백그라운드에서 켜고 브라우저를 엽니다. 이미 켜져 있으면 기존 서버를 사용합니다. |
| `2` · Stop | 이 메뉴나 시작 파일로 실행한 서버를 종료합니다. |
| `3` · Status | 실행 여부와 주소를 확인합니다. |
| `0` · Exit menu | 메뉴만 닫습니다. 서버는 계속 실행됩니다. |

**`start-server.cmd`**는 서버 시작, **`stop-server.cmd`**는 서버 종료를 바로 실행합니다. 파일은 다른 작업 폴더에서 실행해도 동작합니다. PATH의 Node.js 20 이상을 먼저 찾고, 없으면 현재 컴퓨터의 Codex 번들 Node 경로를 자동 확인합니다. 직접 경로를 지정하려면 `ECON_NODE` 환경 변수를 설정합니다.

포트를 바꾸거나 터미널에서 상태를 확인할 수도 있습니다.

```powershell
.\start-server.cmd -Port 5174
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\server.ps1 -Action status
.\stop-server.cmd
```

브라우저를 열지 않고 실행하려면 `start-server.cmd -NoBrowser`를 사용합니다. 사용 중인 포트는 오류로 안내하며 기존 프로그램을 종료하지 않습니다. 다른 데스크톱의 세 .cmd 실행 파일에 기기 전용 수정본과 skip-worktree 설정이 있는 경우 이를 유지하고 GitHub에 올리지 않습니다. 현재 실행 파일은 저장소에서 삭제하지 않습니다.

서버 기록과 로그는 Git에서 제외된 `.local/server.json`, `.local/server.stdout.log`, `.local/server.stderr.log`에 보관합니다. 아래의 직접 Node 실행 방식으로 켠 서버는 해당 터미널의 Ctrl+C로 종료합니다.

Node.js 20 이상에서 별도의 의존성 설치 없이 실행합니다.

```sh
node scripts/dev-server.mjs
```

현재 컴퓨터의 일반 PowerShell에서 `node`를 찾지 못하면, Codex에 포함된 실행 파일을 직접 사용합니다. 아래 경로의 Node.js 24.22.1 실행을 확인했습니다.

```powershell
cd "C:\Users\htt06\OneDrive\바탕 화면\econ-app"
& "C:\Users\htt06\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin\node.exe" scripts/dev-server.mjs
```

이 경로는 현재 컴퓨터의 Codex 런타임 경로입니다. 다른 환경에서는 Node.js 20 이상을 준비한 뒤 `node` 명령을 사용합니다. 서버를 종료할 때는 실행한 PowerShell 창에서 Ctrl+C를 누릅니다. `EADDRINUSE` 오류는 이미 같은 포트의 서버가 실행 중이라는 뜻입니다.

브라우저에서 [앱 열기](http://127.0.0.1:5173/)로 접속합니다.

## 그리기와 편집

- **공통 맞춤 표시:** 점·점선·곡선 그리기와 직선/곡선 이동에서 **대상 선 강조 + 이중 원 + 맞춤 문구**를 같은 방식으로 표시합니다. 모든 자석은 **16px에서 붙고 24px를 넘으면 해제**되며 Alt로 생략합니다. 곡선을 그릴 때도 **접점 맞춤**이 표시되고 Alt/Shift는 포인터가 멈춰 있어도 반영됩니다. [UI 공통 규칙](docs/ui-consistency.md)에 구현·확장 기준을 정리했습니다.

- **칠하기:** 도구막대 **칠하기** → 닫힌 구역에 마우스를 올려 미리보기 → **한 번 클릭**합니다. 구역마다 **다른 색과 A·B·C…**를 자동으로 붙이고 Z 다음은 AA로 이어집니다. 패널에 다음 구역의 색·글자를 표시하며 진하기만 조절하시면 됩니다. 같은 구역 재클릭은 기존 색·글자를 유지하고, 선택 도구로 구역을 클릭하면 색·진하기 변경과 이동·삭제·되돌리기가 가능합니다. 내부의 다른 닫힌 구역은 비워 두며 직선·곡선·점선·좌표축을 경계로 사용합니다. 격자·화면 테두리는 경계가 아니고 현재 화면 안에서 완전히 닫힌 곳만 칠합니다. 칠한 모양은 경계선과 독립적으로 유지됩니다.

캔버스 위에는 **선택 · 직선 · 곡선 · 점 · 점선 · 칠하기**을 둡니다. 현재 도구만 강조하고 그 아래에 현재 작업을 표시합니다. 오른쪽 위에는 현재 작업 또는 선택한 도형의 설정 하나를, 아래에는 도형 목록을 표시합니다. UI 정리의 근거와 참고 자료는 [사용성 정리](docs/ui-design.md)에 기록했습니다.

- **여러 도형 선택·삭제:** 선택 도구에서 빈 공간을 드래그하면 영역에 닿는 도형을 함께 선택합니다. **Ctrl/Cmd+클릭**으로 추가·해제하고 **Shift+영역 드래그**로 기존 선택에 추가합니다. 도구막대 **삭제 / N개 삭제**, 선택 패널 **선택한 N개 삭제**, **Delete·Backspace**로 지웁니다. 입력란에서는 글자만 편집합니다. 삭제는 한 번에 되돌릴 수 있습니다. 빈 공간 클릭·Esc로 선택을 해제하고 도형 하나를 클릭하면 개별 이동·편집으로 돌아갑니다.
- **선택**은 기본 도구입니다. 도형을 클릭해 선택하고 드래그하거나 방향키로 옮깁니다. **Shift+드래그**는 마우스를 더 많이 움직인 방향에 따라 수평·수직으로만 이동합니다. 직선·기본/자유 곡선·점·점선 전체와 자유 곡선의 세 점·점선 끝점에 적용하며 회전·휘어짐 조절에는 적용하지 않습니다. Shift+방향키는 더 크게 이동합니다. 빈 평면이나 그래프 제목을 누르면 선택을 해제합니다. 생성·복제·합산 중 **Esc** 또는 오른쪽 닫기 버튼으로 선택에 돌아갑니다.
- 선택 도구로 **직선을 이동**하면 같은 그래프의 자유 곡선·기본 곡선에 접하는 위치에서 자석처럼 붙고 **접점**이 표시됩니다. 기울기는 유지하며 16px 이내에서 붙고 24px보다 멀어지면 풀립니다. **Alt**를 누른 채 드래그하면 자유롭게 이동합니다. 놓은 뒤에는 독립된 직선이며 곡선의 이후 변경을 따라가는 연결은 만들지 않습니다.
- 직선의 **x/y절편을 다른 도형의 절편이나 원점에 맞출 때**도 자석 보정을 적용합니다. 기울기·Shift 이동 축을 유지하고 16px 포착/24px 해제·Alt 생략을 사용합니다. 점 찍기는 절편 근처 16px에서 정확한 축 교차 좌표로 붙고 **x절편·y절편·원점**을 표시합니다. 축에서 선을 띄워도 절편은 잡을 수 있습니다.
- **곡선 전체를 이동**해 직선에 접하게 붙이는 것도 가능합니다. 복제한 곡선도 모양을 유지한 채 직선의 현재 기울기에 맞는 접점으로 맞춰집니다. 자유 이동·Shift 수평/수직 이동·Alt 자유 배치와 같은 16px 포착/24px 해제를 사용합니다. 원본·직선은 유지하며 새 연결을 만들지 않습니다. 지나는 접선이 없는 방향에서는 자유 이동을 유지하고 곡선을 임의로 변형하지 않습니다.
- **곡선을 다른 곡선 가까이 끌면** 서로 접하는 위치에 붙고 **접점 맞춤**과 두 곡선의 강조를 표시합니다. 기본·자유 곡선은 형태를 유지해 평행이동하며, PPC/무차별곡선은 기존 확대·축소나 준선형 축 이동을 유지합니다. 16px 포착/24px 유지·Alt 해제·자유 곡선의 Shift 방향 제한·한 번 되돌리기를 공유합니다. 실제 접점이 없는 단순 교차, 곡선 전체가 일치하는 겹침, 완전보완재의 꺾임에는 이 접점 자석을 적용하지 않습니다. 놓은 뒤 새 따라가기 관계는 생기지 않습니다.
- 곡선끼리 접한 지점에는 **점 생성/이동·점선 생성/끝점/전체 이동**도 똑같이 붙습니다. 이동 자석과 점/점선이 원본 접점 계산을 공유하며 놓은 뒤에도 **접점 맞춤**과 두 곡선 강조를 유지합니다. Alt·보정 OFF·Shift 제한도 각 도구의 공통 규칙을 따릅니다.
- **찍어 둔 점 근처로 직선·곡선을 이동**하면 그 점을 정확히 지나도록 붙고 **점 맞춤**이 표시됩니다. 직선 기울기와 곡선 모양·점 위치를 유지하며 Shift 방향 제한·Alt 생략·16px 포착/24px 해제를 사용합니다. 더 가까운 명시적 점은 절편·접선 보정에서 이어받을 수 있습니다. 새 따라가기 연결은 만들지 않으며 움직이는 도형 자신의 최저점처럼 함께 움직이는 점은 대상에서 제외합니다.
- **직선**은 클릭할 때마다 추가합니다. 선택한 직선의 기울기를 숫자·슬라이더·프리셋 또는 흰색 손잡이로 바꿉니다. 정확한 수직선도 지원합니다.
- **곡선 → 기본 곡선 → PPC**로 원점 중심의 ¼원호를 추가합니다. 축 위 두 끝점을 끌거나 **가로·세로 반지름**을 각각 바꾸면 타원이 됩니다. 몸체는 비율을 유지해 크기를 바꾸고, 모양 손잡이·**세로 / 가로 비율** 슬라이더는 면적을 유지해 비율을 바꿉니다. 복제·점/접선 맞춤·칠하기·되돌리기를 공유합니다. 중심 이동·회전·합산은 제공하지 않습니다.
- **곡선 → 기본 곡선 → 직각 쌍곡선**으로 `xy = k`의 양수 가지를 추가합니다. 몸체 이동·크기 손잡이·**크기** 슬라이더는 가로·세로 축을 점근선으로 유지하며 크기만 바꿉니다. 복제·점/접선 자석·되돌리기를 공유합니다. 음수 가지·점근선 이동·이 곡선의 합산은 제공하지 않습니다.
- **곡선 → 무차별곡선**에서 콥더글라스·완전대체재·완전보완재·준선형효용을 추가합니다. 함수 입력 없이 흰색 모양 손잡이와 슬라이더로 조절합니다. 콥더글라스·완전보완재는 원점 기준 확대·축소, 완전대체재는 기울기를 유지한 평행이동, 준선형은 기본 y축 평행이동이며 **선형 축**에서 x축으로 바꿉니다. 고유 이동은 Shift보다 우선하고 Alt는 자석만 생략합니다. 같은 선호의 다른 수준은 **복제 후 몸체 이동**으로 만듭니다. 직선 맞춤은 매끄러운 접점·완전보완재 꺾임·완전대체재 축 모서리를 사용합니다. 기존 직선·곡선을 복제해 가격효과 도식을 직접 구성할 수 있습니다. 자동 분해·효용함수 입력·무차별곡선 합산은 제공하지 않습니다. [조작과 제한](docs/indifference-design.md)을 참고하십시오.
- **곡선**은 시작점 → 끝점 → 지나는 점을 클릭해 만듭니다. 그래프 안에 **1/3 시작점 · 2/3 끝점 · 3/3 지나는 점**과 좌클릭·Esc 조작이 표시됩니다. 세 번째 점을 직선 위에 찍으면 접점이 연결됩니다. Alt는 자동 연결·스냅을 생략합니다. 가운데 방향은 자동/수평/수직이며, 미완성 곡선은 Esc·도구/그래프/기록 전환에서 취소됩니다.
- 곡선 버튼의 작은 펼침 메뉴를 제거하고, 곡선 그리기 패널의 **기본 곡선**에 방향 그림이 있는 **우하향 + / 우상향 +** 버튼을 뒀습니다. 한 번 눌러 추가하며 다음 곡선 버튼은 그대로 세 점 그리기를 시작합니다. 기본 곡선은 양 끝 접선을 따라 작업 영역 경계까지 이어지고 자유 곡선은 시작점부터 끝점까지만 그립니다. 곡선 그리기 포인터는 점 도구와 같은 원형·좌표 표시를 사용합니다.
- 자유 곡선은 세 점·접선 방향·양쪽 휘어짐 손잡이로 직접 조절합니다. 오른쪽 **∪·∩·⊂·⊃** 모양 버튼과 **휘어짐 조절**을 제공합니다. 수동 **직선에 접하기** 메뉴는 제거했습니다. 곡선을 그릴 때의 자동 접점 연결과 직선을 이동할 때의 접선 자석 보정은 유지합니다. 연결된 접점은 원본 직선을 따라가며 **연결 해제** 후 자유 편집합니다. 선택한 도형만 편집 손잡이를 표시합니다.
- 자유 곡선의 **최저점 표시** → 생성된 점의 **이 점을 지나는 직선**으로 최저점을 지나는 선을 만듭니다. 곡선을 바꾸면 점과 선이 따라갑니다. 최저점은 유한 곡선 전체에서 계산하므로 끝점일 수도 있습니다. 일반 점에도 통과 직선을 만들 수 있습니다.
- **점**은 좌클릭으로 만듭니다. 마우스 조정은 기본 ON이며 Alt로 잠시 생략합니다. 복제한 직선을 이동해 맞춘 자유 곡선의 접점에도 정확히 붙고 포인터에 **접점**이 표시됩니다. **추가 설정**에서 점 생성 ON/OFF와 새 점의 좌표 표시를 바꿉니다. 기존 점은 선택 후 좌표 표시를 편집합니다. 우클릭은 점을 만들지 않으며 일반 점은 원본 선의 이후 이동을 따라가지 않습니다.
- **점선**은 두 위치를 클릭하거나 드래그해 만듭니다. 자유/수평/수직 방향과 Shift 방향 제한을 지원하며, 찍어 둔 점에서 시작해 사선에 수평·수직으로 정확히 붙일 수 있습니다. 생성·끝점 편집·전체 이동 모두 **16px 포착/24px 해제**와 **Alt 보정 생략**을 공유합니다. 붙으면 이중 원·**선 맞춤/점 맞춤/교점**과 대상 선·점선 강조를 표시합니다. 전체 이동은 양 끝점 중 하나를 붙이고 길이·각도를 유지합니다. **마우스 보정**은 점 도구와 별도로 기본 ON이며, 따라가기 연결·길이·측정 눈금은 만들지 않습니다.
- 캔버스 위 도구막대의 **복제** 버튼에서 원본을 고르고 복제합니다. 직선은 그대로/기울기 ×2/×½를 선택하고 식을 미리 봅니다. 기울기는 현재 기준점을 중심으로 바꾸며 사본은 자동으로 옆에 생성합니다. 반복 복제도 이미 놓인 사본과 같은 자리를 피하고 수평선은 위쪽, 수직선은 옆쪽으로 띄웁니다. 기준점·절편 유지·배치 선택 메뉴는 없으며 하위 항목이 있을 때만 **하위 항목 함께**를 표시합니다. 전체 복제는 한 undo 단계이고 원본을 유지합니다. 복제본은 기존 따라가기 관계를 끊은 독립 사본입니다.
- 위쪽 **합치기**에서 같은 그래프의 직선·기본 곡선을 두 개 이상 선택해 수직합/수평합을 만듭니다. 원본 변경을 자동 반영하고, 기본 음수 기여분 0 처리 또는 부호를 유지한 수학적 합을 고릅니다. 합 추가 후 결과 편집으로 돌아갑니다. 자유 곡선·다른 그래프의 합산, 합 자체의 이동·복제는 지원하지 않습니다.
- **도형** 목록은 종류를 섞은 생성 순서입니다. 항목을 드래그하거나 선택한 도형의 **분류**를 펼쳐 상위 항목을 지정합니다. 폴더 버튼으로 폴더를 만듭니다. 계층은 좌표 이동과 독립적이며, 삭제한 항목의 자식은 상위로 남습니다.
- 원본을 삭제하면 접점·최저점·통과 직선의 종속 도형은 현재 형태로 남고 연결만 해제합니다. 합산 결과는 원본과 함께 삭제됩니다. 삭제·연결·복제는 모두 되돌릴 수 있습니다.

## 그래프와 저장

- 첫 작업 영역의 **포맷 → 에지워드 상자**에서 가로·세로 총량을 정합니다(기본 10×8). 왼쪽 아래 A 원점과 오른쪽 위 B 원점의 축을 한 상자에 표시하며 네 변에 점·점선을 맞추고 구역을 칠할 수 있습니다. 이후 **그래프 설정**에서 총량·B 축 이름을 바꿉니다. 도형은 A 기준 수학 좌표로 저장되며 화면 크기가 달라져도 상자 비율을 유지합니다. B 방향 곡선은 세 점 자유 곡선으로 직접 그립니다.
- 상단 **그래프 설정**에서 활성 그래프의 이름·사분면·축 이름·x/y 방향·축 간격을 바꿉니다. 입력은 즉시 반영되고 완료/닫기로 캔버스에 돌아갑니다. 이름을 비우면 해당 축 이름만 숨깁니다. 축 반전은 투영만 바꾸고 내부 좌표·기울기는 유지합니다.
- **축에서 선 띄우기**의 기본 간격은 0.75, 범위는 0.25~2 좌표 단위입니다. 표시·일반 선 위 스냅만 잘라 원본을 유지하고 점·점선은 자르지 않습니다. 절편 스냅은 실제 축 교차 좌표에서 계속 사용할 수 있습니다. **도형 전체 삭제**는 그래프 설정 아래에 있으며 활성 그래프만 비우고 undo할 수 있습니다.
- 처음 열리는 작업 영역에서 배치·사분면을 정합니다. 이후 상단 **배치 · N개**로 바꿉니다. 가로/세로 2·3개, ㄴ자, 좌우/상하 대면, 격자와 최대 3×3 직접 배치를 지원합니다. 배치를 줄여도 숨긴 그래프를 보관합니다.
- 그래프 제목·평면을 눌러 편집할 그래프를 선택합니다. 도형·축·격자·삭제는 활성 그래프에 적용합니다. 다른 그래프로 전환하면 복제·합산 작업은 닫힙니다. 좁은 화면에서도 그래프 배치의 행·열 위치를 유지하고 그래프 영역 안에서 스크롤합니다.
- 상단 **되돌리기 / 다시 실행**, **Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y**를 지원합니다. 드래그·슬라이더·텍스트 입력은 한 단계로 묶고 최근 100단계를 보관합니다. 입력란에서는 기본 텍스트 편집 단축키를 유지합니다.
- 상단 **저장**은 JSON 내보내기입니다. 내용을 복사하거나 econ-studio.json을 다운로드합니다. 현재는 메모리 상태여서 새로고침하면 초기화되며 JSON 불러오기·자동 저장은 지원하지 않습니다.

JSON의 `schemaVersion`은 10입니다. `layout.slots`에 그래프 ID와 행·열을, `diagrams`에 숨겨진 그래프까지 모두 기록합니다. 최상위의 기존 도형·좌표계 필드는 `activeDiagramId`에 해당하는 선택한 그래프의 사본입니다. `coordinateSystem`에 선택한 사분면, 원점 배치, 축 이름(`axisNames`)과 축 표시(`axesVisible: true`)를 기록합니다. 축과 이름이 잘리지 않도록 그래프 주변에 여백을 두며, 1사분면의 원점은 그래프 왼쪽 아래, 1·2사분면은 중앙 아래, 전체 사분면은 화면 중앙입니다. 기본은 x가 오른쪽, y가 위쪽으로 증가하며, 반전 시 `xPositive`, `yPositive`와 원점 위치도 함께 기록합니다. 위치는 화면 픽셀이 아닌 내부 좌표로 보관합니다.

모든 `lines`는 ID·이름·색상·기울기(`slope`)·절편(`intercept`)·기준점(`anchor`)과 일반형 계수(`implicit`: `a*x + b*y + c = 0`)를 포함합니다. 수직선은 `vertical: true`, `slope: null`, `intercept: null`, `xIntercept`로 기록합니다. 유한하지만 매우 큰 기울기의 절편이 숫자 표현 범위를 넘으면 `intercept`는 `null`이며 기준점과 일반형 계수로 직선을 표현합니다.

`curves`에는 무차별곡선도 포함하며 이 객체는 `family`, `anchor`, `shape`, 준선형의 `linearAxis`와 `geometry.type=indifference`를 사용합니다. 아래 이차식과 접선 연장은 기존 기본 곡선에만 해당합니다.

기본 곡선은 우상향·우하향 방향(`variant`), 기준점(`anchor`), 가운데 구간의 반폭(`span`), 중심 기울기(`slope`), 휘어짐(`bend`)과 내부 좌표의 이차 베지어 제어점(`geometry.controlPoints`)을 포함합니다. 가운데 구간은 `-1 ≤ t ≤ 1`에서 `x = anchor.x + span*t`, `y = anchor.y + span*(slope*t + bend*t²)`로 정의됩니다. 양 끝의 접선 연장 정보는 `geometry.extensions`에 함께 출력합니다. 화면에서는 이 구간과 연장 부분을 선택한 사분면의 작업 영역 경계에서 자릅니다.

`points`는 이름·내부 좌표·좌표 표시 옵션, `dashedLines`는 점선의 시작점(`anchor`)·끝점(`end`), `groups`는 폴더 이름을 포함합니다. 모든 항목의 `parentId`가 계층을 기록하고 `objectOrder`는 종류를 섞은 생성 순서를 기록합니다. 상세 정의는 [JSON 형식](docs/json-format.md)을 참고하십시오.

```sh
node scripts/check.mjs
node scripts/test.mjs
node scripts/build.mjs
node scripts/browser-test.mjs
```

## GitHub Pages

`node scripts/build.mjs`로 만든 `dist/`는 정적 웹 파일입니다. 앱 경로는 GitHub Pages의 `/econ-app/` 하위 경로를 고려한 상대 경로입니다. 저장소 루트 자체도 정적 사이트로 제공할 수 있습니다. 자동 배포는 설정하지 않았으며 실제 배포 검증은 아직 하지 않았습니다.

작업은 메모리에 보관하므로 새로고침하면 초기화됩니다. JSON으로 결과를 저장할 수 있으며, JSON 불러오기와 자동 저장은 아직 지원하지 않습니다.
